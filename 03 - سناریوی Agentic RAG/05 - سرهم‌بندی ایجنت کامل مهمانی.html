خانه/۰۳ — سناریوی Agentic RAG/سرهم‌بندی ایجنت کامل مهمانی

ساخت ایجنت جشن شما

حالا که همه اجزای لازم برای آلفرد را ساخته‌ایم، وقت آن است که همه‌چیز را در یک ایجنت کامل کنار هم بگذاریم تا بتواند به میزبانی جشن مجلل ما کمک کند.

در این بخش، ابزارهای بازیابی اطلاعات مهمانان، جستجوی وب، اطلاعات آب‌وهوا و آمار Hub را در یک ایجنت قدرتمند ترکیب می‌کنیم.

سرهم‌بندی آلفرد: ایجنت کامل

به جای پیاده‌سازی مجدد همه ابزارهایی که در بخش‌های قبل ساختیم، آن‌ها را از ماژول‌های مربوطه‌شان که در فایل‌های tools.py و retriever.py ذخیره کردیم import می‌کنیم.

نکته: اگر هنوز ابزارها را پیاده نکرده‌اید، به بخش‌های ابزارها و بازیاب برگردید، آن‌ها را پیاده کنید و به فایل‌های tools.py و retriever.py اضافه کنید.

ابتدا کتابخانه‌ها و ابزارهای لازم را از بخش‌های قبل import می‌کنیم:

smolagents

LangGraph

# Initialize the web search tool
search_tool = DuckDuckGoSearchRun()

# Generate the chat interface, including the tools
llm = HuggingFaceEndpoint(
    repo_id="Qwen/Qwen2.5-Coder-32B-Instruct",
    huggingfacehub_api_token=HUGGINGFACEHUB_API_TOKEN,
)

chat = ChatHuggingFace(llm=llm, verbose=True)
tools = [guest_info_tool, search_tool, weather_info_tool, hub_stats_tool]
chat_with_tools = chat.bind_tools(tools)

# Generate the AgentState and Agent graph
class AgentState(TypedDict):
    messages: Annotated[list[AnyMessage], add_messages]

def assistant(state: AgentState):
    return {
        "messages": [chat_with_tools.invoke(state["messages"])],
    }

## The graph
builder = StateGraph(AgentState)

# Define nodes: these do the work
builder.add_node("assistant", assistant)
builder.add_node("tools", ToolNode(tools))

# Define edges: these determine how the control flow moves
builder.add_edge(START, "assistant")
builder.add_conditional_edges(
    "assistant",
    # If the latest message requires a tool, route to tools
    # Otherwise, provide a direct response
    tools_condition,
)
builder.add_edge("tools", "assistant")
alfred = builder.compile()

بیایید ببینیم آلفرد چگونه می‌تواند در اطلاعات مهمانان به ما کمک کند.

قابلیت پیشرفته: حافظه گفتگو

برای اینکه آلفرد در طول جشن باز هم مفیدتر باشد، می‌توانیم حافظه گفتگو را فعال کنیم تا تعامل‌های قبلی را به خاطر بسپارد:

smolagents

# Create Alfred with conversation memory
alfred_with_memory = CodeAgent(
    tools=[guest_info_tool, weather_info_tool, hub_stats_tool, search_tool], 
    model=model,
    add_base_tools=True,
    planning_interval=3
)

# First interaction
response1 = alfred_with_memory.run("Tell me about Lady Ada Lovelace.")
print("🎩 Alfred's First Response:")
print(response1)

# Second interaction (referencing the first)
response2 = alfred_with_memory.run("What projects is she currently working on?", reset=False)
print("🎩 Alfred's Second Response:")
print(response2)

LlamaIndex

from llama_index.core.workflow import Context

alfred = AgentWorkflow.from_tools_or_functions(
    [guest_info_tool, search_tool, weather_info_tool, hub_stats_tool],
    llm=llm
)

# Remembering state
ctx = Context(alfred)

# First interaction
response1 = await alfred.run("Tell me about Lady Ada Lovelace.", ctx=ctx)
print("🎩 Alfred's First Response:")
print(response1)

# Second interaction (referencing the first)
response2 = await alfred.run("What projects is she currently working on?", ctx=ctx)
print("🎩 Alfred's Second Response:")
print(response2)

توجه کنید که هیچ‌کدام از این سه رویکرد ایجنت، حافظه را مستقیماً به ایجنت گره نمی‌زنند. آیا دلیل خاصی برای این انتخاب طراحی وجود دارد 🧐؟

  • smolagents: حافظه بین اجراهای مختلف حفظ نمی‌شود؛ باید آن را صریحاً با reset=False مشخص کنید.
  • LlamaIndex: برای مدیریت حافظه در طول یک اجرا، باید صریحاً یک شیء context اضافه کنید.
  • LangGraph: گزینه‌هایی برای بازیابی پیام‌های قبلی یا استفاده از کامپوننت اختصاصی MemorySaver ارائه می‌دهد.

جمع‌بندی

تبریک! شما با موفقیت آلفرد را ساختید؛ ایجنتی پیشرفته که با چندین ابزار مجهز شده تا در میزبانی مجلل‌ترین جشن قرن کمک کند. آلفرد اکنون می‌تواند:

  1. اطلاعات دقیق مهمانان را بازیابی کند
  2. شرایط آب‌وهوا را برای برنامه‌ریزی فعالیت‌های فضای باز بررسی کند
  3. درباره سازندگان تأثیرگذار هوش مصنوعی و مدل‌هایشان بینش ارائه دهد
  4. برای دریافت آخرین اطلاعات در وب جستجو کند
  5. زمینه گفتگو را با حافظه حفظ کند

با این قابلیت‌ها، آلفرد آماده است تا با توجه شخصی‌سازی‌شده و اطلاعات به‌روز، مهمانان را تحت تأثیر قرار دهد و موفقیت درخشان جشن شما را تضمین کند.
