استفاده از ابزارها در LlamaIndex

تعریف یک مجموعه‌ی روشن از ابزارها (Tools) برای عملکرد حیاتی است. همان‌طور که در فصل ۱ بحث کردیم، رابط‌های روشن ابزار برای LLMها راحت‌تر قابل‌استفاده هستند. درست مانند رابط‌های API نرم‌افزاری برای مهندسان انسانی، اگر فهمیدن نحوه‌ی کار ابزار آسان باشد، می‌توانند بهره‌ی بیشتری از آن ببرند.

چهار نوع اصلی ابزار در LlamaIndex وجود دارد:

  1. FunctionTool: هر تابع پایتونی را به ابزاری تبدیل می‌کند که ایجنت بتواند از آن استفاده کند. این ابزار به‌طور خودکار می‌فهمد تابع چگونه کار می‌کند.
  2. QueryEngineTool: ابزاری که به ایجنت‌ها اجازه می‌دهد از query engineها استفاده کنند. از آنجا که ایجنت‌ها بر پایه‌ی query engineها ساخته شده‌اند، می‌توانند از ایجنت‌های دیگر هم به‌عنوان ابزار استفاده کنند.
  3. Toolspecs: مجموعه‌هایی از ابزارها که توسط جامعه ساخته شده‌اند و اغلب شامل ابزارهایی برای سرویس‌های خاص مانند Gmail هستند.
  4. Utility Tools: ابزارهای ویژه‌ای که به مدیریت حجم زیاد داده از ابزارهای دیگر کمک می‌کنند.

در ادامه هر یک را با جزئیات بیشتر بررسی می‌کنیم.

ساخت یک FunctionTool

💡 نکته

می‌توانید کد را در این نوت‌بوک دنبال کنید که با Google Colab قابل اجراست.

FunctionTool راهی ساده برای پوشاندن (Wrap) هر تابع پایتون و در دسترس قرار دادن آن برای ایجنت است. می‌توانید یک تابع همگام (Synchronous) یا ناهمگام (Asynchronous) را به همراه پارامترهای اختیاری name و description به ابزار بدهید. نام و توضیحات به‌ویژه مهم هستند، چون به ایجنت کمک می‌کنند بفهمد چه زمانی و چگونه از ابزار به‌طور مؤثر استفاده کند. در ادامه می‌بینیم چگونه یک FunctionTool بسازیم و سپس آن را فراخوانی کنیم.

from llama_index.core.tools import FunctionTool

def get_weather(location: str) -> str:
    """Useful for getting the weather for a given location."""
    print(f"Getting weather for {location}")
    return f"The weather in {location} is sunny"

tool = FunctionTool.from_defaults(
    get_weather,
    name="my_weather_tool",
    description="Useful for getting the weather for a given location.",
)
tool.call("New York")
💡 نکته

هنگام استفاده از یک ایجنت یا LLM دارای function calling، ابزار انتخاب‌شده (و آرگومان‌هایی که برای آن نوشته می‌شود) به‌شدت به نام ابزار و توضیحِ هدف و آرگومان‌های آن وابسته است. درباره‌ی function calling در راهنمای Function Calling بیشتر بخوانید.

ساخت یک QueryEngineTool

همان QueryEngineای که در بخش قبل تعریف کردیم را می‌توان به‌سادگی با کلاس QueryEngineTool به یک ابزار تبدیل کرد. در مثال زیر می‌بینیم چگونه از یک QueryEngine یک QueryEngineTool بسازیم.

import chromadb
from llama_index.core import VectorStoreIndex
from llama_index.core.tools import QueryEngineTool
from llama_index.llms.huggingface_api import HuggingFaceInferenceAPI
from llama_index.embeddings.huggingface import HuggingFaceEmbedding
from llama_index.vector_stores.chroma import ChromaVectorStore

embed_model = HuggingFaceEmbedding("BAAI/bge-small-en-v1.5")

db = chromadb.PersistentClient(path="./alfred_chroma_db")
chroma_collection = db.get_or_create_collection("alfred")
vector_store = ChromaVectorStore(chroma_collection=chroma_collection)

index = VectorStoreIndex.from_vector_store(vector_store, embed_model=embed_model)

llm = HuggingFaceInferenceAPI(model_name="Qwen/Qwen2.5-Coder-32B-Instruct")
query_engine = index.as_query_engine(llm=llm)
tool = QueryEngineTool.from_defaults(query_engine, name="some useful name", description="some useful description")

ساخت Toolspecها

ToolSpecها را مجموعه‌هایی از ابزارها در نظر بگیرید که هماهنگ با هم کار می‌کنند، مانند یک جعبه‌ابزار حرفه‌ای و سازمان‌یافته. همان‌طور که جعبه‌ابزار یک مکانیک شامل ابزارهای مکمل برای تعمیر خودرو است، یک ToolSpec ابزارهای مرتبط را برای اهداف مشخص ترکیب می‌کند. برای مثال، ToolSpec یک ایجنت حسابداری ممکن است قابلیت‌های صفحه‌گسترده، ایمیل و ابزارهای محاسباتی را به‌زیبایی یکپارچه کند تا وظایف مالی را با دقت و کارایی انجام دهد.

نصب Google Toolspec

همان‌طور که در بخش LlamaHub معرفی شد، می‌توانیم Google toolspec را با دستور زیر نصب کنیم:

pip install llama-index-tools-google

و اکنون می‌توانیم toolspec را بارگذاری کنیم و آن را به فهرستی از ابزارها تبدیل کنیم.

from llama_index.tools.google import GmailToolSpec

tool_spec = GmailToolSpec()
tool_spec_list = tool_spec.to_tool_list()

برای نمایی دقیق‌تر از ابزارها، می‌توانیم به metadata هر ابزار نگاه کنیم.

[(tool.metadata.name, tool.metadata.description) for tool in tool_spec_list]

پروتکل Model Context Protocol (MCP) در LlamaIndex

LlamaIndex همچنین اجازه می‌دهد از ابزارهای MCP از طریق یک ToolSpec در LlamaHub استفاده کنید. کافی است یک سرور MCP را اجرا کنید و با پیاده‌سازی زیر شروع به استفاده از آن کنید.

اگر می‌خواهید بیشتر درباره‌ی MCP بدانید، می‌توانید دوره‌ی رایگان MCP ما را ببینید.

نصب MCP Toolspec

همان‌طور که در بخش LlamaHub معرفی شد، می‌توانیم MCP toolspec را با دستور زیر نصب کنیم:

pip install llama-index-tools-mcp
from llama_index.tools.mcp import BasicMCPClient, McpToolSpec

# فرض می‌کنیم یک سرور MCP روی 127.0.0.1:8000 در حال اجراست، یا می‌توانید از کلاینت MCP برای اتصال به سرور MCP خودتان استفاده کنید.
mcp_client = BasicMCPClient("http://127.0.0.1:8000/sse")
mcp_tool = McpToolSpec(client=mcp_client)

# دریافت ایجنت
agent = await get_agent(mcp_tool)

# ساخت کانتکست ایجنت
agent_context = Context(agent)

ابزارهای کمکی (Utility Tools)

اغلب، پرس‌وجوی مستقیم از یک API می‌تواند حجم بیش‌ازحدی از داده برگرداند، که بخشی از آن ممکن است نامرتبط باشد، از پنجره‌ی کانتکست LLM سرریز شود یا تعداد توکن‌های مصرفی را بی‌دلیل افزایش دهد. بیایید دو ابزار کمکی اصلی را مرور کنیم.

  1. OnDemandToolLoader: این ابزار هر data loader موجود در LlamaIndex (کلاس BaseReader) را به ابزاری تبدیل می‌کند که ایجنت بتواند از آن استفاده کند. این ابزار را می‌توان با تمام پارامترهای لازم برای راه‌اندازی load_data از data loader، به‌همراه یک رشته‌ی کوئری به زبان طبیعی فراخوانی کرد. در حین اجرا، ابتدا داده را از data loader بارگذاری می‌کنیم، آن را ایندکس می‌کنیم (مثلاً با یک vector store) و سپس «در لحظه‌ی نیاز» (On-demand) از آن پرس‌وجو می‌کنیم. هر سه گام در یک فراخوانی ابزار انجام می‌شوند.
  2. LoadAndSearchToolSpec: این ابزار هر Tool موجود را به‌عنوان ورودی می‌گیرد. چون یک tool spec است، to_tool_list را پیاده‌سازی می‌کند و هنگام فراخوانی آن، دو ابزار برگردانده می‌شود: یک ابزار بارگذاری (Load) و یک ابزار جستجو (Search). اجرای ابزار بارگذاری، ابزار زیربنایی را فراخوانی می‌کند و سپس خروجی را ایندکس می‌کند (به‌صورت پیش‌فرض با یک ایندکس برداری). اجرای ابزار جستجو یک رشته‌ی کوئری را به‌عنوان ورودی می‌گیرد و ایندکس زیربنایی را فراخوانی می‌کند.
💡 نکته

toolspecها و utility toolها را در LlamaHub پیدا می‌کنید.
