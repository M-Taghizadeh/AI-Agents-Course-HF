خانه/۰۲ — فریم‌ورک‌های ایجنت/LlamaIndex/آشنایی با LlamaHub

آشنایی با LlamaHub

LlamaHub یک رجیستری شامل صدها ادغام (Integration)، ایجنت و ابزار است که می‌توانید در LlamaIndex استفاده کنید.

ما در این دوره از ادغام‌های متنوعی استفاده خواهیم کرد، پس ابتدا نگاهی به LlamaHub می‌اندازیم و می‌بینیم چگونه می‌تواند به ما کمک کند.

بیایید ببینیم چگونه وابستگی‌های (Dependencies) کامپوننت‌های موردنیازمان را پیدا و نصب کنیم.

نصب

دستورالعمل‌های نصب LlamaIndex به‌صورت یک نمای کلی ساختارمند در LlamaHub در دسترس است. شاید در نگاه اول کمی گیج‌کننده باشد، اما بیشتر دستورهای نصب از یک قالب ساده و به‌یادماندنی پیروی می‌کنند:

pip install llama-index-{component-type}-{framework-name}

بیایید وابستگی‌های یک کامپوننت LLM و امبدینگ را با استفاده از ادغام Hugging Face inference API نصب کنیم.

pip install llama-index-llms-huggingface-api llama-index-embeddings-huggingface

استفاده

پس از نصب، می‌توانیم الگوهای استفاده را ببینیم. متوجه می‌شوید که مسیرهای import از دستور نصب پیروی می‌کنند! در ادامه، نمونه‌ای از استفاده از Hugging Face inference API برای یک کامپوننت LLM را می‌بینیم.

from llama_index.llms.huggingface_api import HuggingFaceInferenceAPI
import os
from dotenv import load_dotenv

# بارگذاری فایل .env
load_dotenv()

# دریافت HF_TOKEN از متغیرهای محیطی
hf_token = os.getenv("HF_TOKEN")

llm = HuggingFaceInferenceAPI(
    model_name="Qwen/Qwen2.5-Coder-32B-Instruct",
    temperature=0.7,
    max_tokens=100,
    token=hf_token,
    provider="auto"
)

response = llm.complete("Hello, how are you?")
print(response)
# I am good, how can I help you today?

عالی! اکنون می‌دانیم چگونه ادغام‌های موردنیاز کامپوننت‌هایمان را پیدا، نصب و استفاده کنیم. بیایید عمیق‌تر به سراغ کامپوننت‌ها برویم و ببینیم چگونه می‌توانیم از آن‌ها برای ساخت ایجنت‌های خودمان استفاده کنیم.
