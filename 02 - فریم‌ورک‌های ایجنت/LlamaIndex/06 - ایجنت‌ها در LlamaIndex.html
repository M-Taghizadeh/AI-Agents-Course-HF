استفاده از ایجنت‌ها در LlamaIndex

آلفرد، پیشخدمت ایجنت مفید ما از قبل را به یاد دارید؟ او در آستانه‌ی یک ارتقاست! اکنون که ابزارهای موجود در LlamaIndex را می‌شناسیم، می‌توانیم قابلیت‌های جدیدی به آلفرد بدهیم تا بهتر به ما خدمت کند.

اما پیش از ادامه، بیایید دوباره یادآوری کنیم چه چیزی یک ایجنت مثل آلفرد را راه می‌اندازد. در فصل ۱ یاد گرفتیم که:

ایجنت سیستمی است که از یک مدل هوش مصنوعی برای تعامل با محیط خود به‌منظور دستیابی به یک هدف تعریف‌شده توسط کاربر استفاده می‌کند. این سیستم استدلال، برنامه‌ریزی و اجرای اقدام (اغلب از طریق ابزارهای خارجی) را ترکیب می‌کند تا وظایف را انجام دهد.

LlamaIndex از سه نوع اصلی ایجنت استدلالی پشتیبانی می‌کند:

  1. Function Calling Agents - با مدل‌های هوش مصنوعی‌ای کار می‌کنند که می‌توانند توابع مشخصی را فراخوانی کنند.
  2. ReAct Agents - می‌توانند با هر هوش مصنوعی‌ای که اندپوینت چت یا متن دارد کار کنند و وظایف استدلالی پیچیده را مدیریت کنند.
  3. Advanced Custom Agents - از روش‌های پیچیده‌تری برای مدیریت وظایف و گردش‌کارهای پیچیده‌تر استفاده می‌کنند.
💡 نکته

اطلاعات بیشتر درباره‌ی ایجنت‌های پیشرفته را در BaseWorkflowAgent پیدا کنید.

مقداردهی اولیه‌ی ایجنت‌ها

💡 نکته

می‌توانید کد را در این نوت‌بوک دنبال کنید که با Google Colab قابل اجراست.

برای ساخت یک ایجنت، ابتدا مجموعه‌ای از توابع/ابزارها را که قابلیت‌های آن را تعریف می‌کنند به آن می‌دهیم. بیایید ببینیم چگونه یک ایجنت با چند ابزار پایه بسازیم. در زمان نگارش این متن، ایجنت به‌طور خودکار از function calling API (در صورت وجود) استفاده می‌کند، یا از یک حلقه‌ی استاندارد ReAct.

LLMهایی که از API ابزار/تابع پشتیبانی می‌کنند نسبتاً جدید هستند، اما راهی قدرتمند برای فراخوانی ابزارها فراهم می‌کنند، چون از پرامپت‌نویسی خاص بی‌نیازند و به LLM اجازه می‌دهند بر اساس schemaهای داده‌شده فراخوانی ابزار بسازد.

ایجنت‌های ReAct هم در وظایف استدلالی پیچیده خوب عمل می‌کنند و با هر LLM‌ای که قابلیت چت یا تکمیل متن دارد کار می‌کنند. آن‌ها پرحرف‌ترند و استدلال پشت برخی اقداماتی را که انجام می‌دهند نشان می‌دهند.

from llama_index.llms.huggingface_api import HuggingFaceInferenceAPI
from llama_index.core.agent.workflow import AgentWorkflow
from llama_index.core.tools import FunctionTool

# تعریف یک ابزار نمونه -- type annotationها، نام تابع و docstringها همگی در schemaهای پارس‌شده لحاظ می‌شوند!
def multiply(a: int, b: int) -> int:
    """Multiplies two integers and returns the resulting integer"""
    return a * b

# مقداردهی اولیه‌ی llm
llm = HuggingFaceInferenceAPI(model_name="Qwen/Qwen2.5-Coder-32B-Instruct")

# مقداردهی اولیه‌ی ایجنت
agent = AgentWorkflow.from_tools_or_functions(
    [FunctionTool.from_defaults(multiply)],
    llm=llm
)

ایجنت‌ها به‌صورت پیش‌فرض بدون حالت (Stateless) هستند، اما می‌توانند با استفاده از یک آبجکت Context تعامل‌های گذشته را به خاطر بسپارند. این ویژگی زمانی مفید است که ایجنتی لازم دارید که تعامل‌های پیشین را به یاد بیاورد، مانند یک چت‌بات که کانتکست را در طول چند پیام حفظ می‌کند یا یک مدیر وظایف که باید پیشرفت را در طول زمان دنبال کند.

# بدون حالت (stateless)
response = await agent.run("What is 2 times 2?")

# به خاطر سپردن حالت (state)
from llama_index.core.workflow import Context

ctx = Context(agent)

response = await agent.run("My name is Bob.", ctx=ctx)
response = await agent.run("What was my name again?", ctx=ctx)

متوجه می‌شوید که ایجنت‌ها در LlamaIndex ناهمگام (Async) هستند، چون از عملگر await پایتون استفاده می‌کنند. اگر با کد ناهمگام در پایتون تازه‌کارید یا نیاز به مرور دارید، یک راهنمای ناهمگام عالی دارند.

اکنون که مبانی را فهمیدیم، ببینیم چگونه می‌توانیم از ابزارهای پیچیده‌تر در ایجنت‌هایمان استفاده کنیم.

ساخت ایجنت‌های RAG با QueryEngineTool

Agentic RAG راهی قدرتمند برای استفاده از ایجنت‌ها جهت پاسخ به سوالات درباره‌ی داده‌های شماست. می‌توانیم ابزارهای مختلفی به آلفرد بدهیم تا در پاسخ به سوالات کمک کند. با این حال، به‌جای اینکه آلفرد به‌طور خودکار روی اسناد به سوال پاسخ دهد، می‌تواند تصمیم بگیرد از هر ابزار یا جریان دیگری برای پاسخ‌گویی استفاده کند.

پوشاندن QueryEngine به‌عنوان یک ابزار برای ایجنت آسان است. هنگام انجام این کار، باید یک نام و توضیح تعریف کنیم. LLM از این اطلاعات برای استفاده‌ی درست از ابزار بهره می‌برد. بیایید ببینیم چگونه با QueryEngineای که در بخش کامپوننت‌ها ساختیم، یک QueryEngineTool بارگذاری کنیم.

from llama_index.core.tools import QueryEngineTool

query_engine = index.as_query_engine(llm=llm, similarity_top_k=3) # همان‌طور که در بخش «کامپوننت‌ها در LlamaIndex» نشان داده شد

query_engine_tool = QueryEngineTool.from_defaults(
    query_engine=query_engine,
    name="name",
    description="a specific description",
    return_direct=False,
)
query_engine_agent = AgentWorkflow.from_tools_or_functions(
    [query_engine_tool],
    llm=llm,
    system_prompt="You are a helpful assistant that has access to a database containing persona descriptions. "
)

ساخت سیستم‌های چندایجنتی

کلاس AgentWorkflow مستقیماً از سیستم‌های چندایجنتی هم پشتیبانی می‌کند. با دادن یک نام و توضیح به هر ایجنت، سیستم همواره یک «گوینده‌ی فعال» نگه می‌دارد، و هر ایجنت می‌تواند کار را به ایجنت دیگری واگذار (Handoff) کند.

با محدود کردن دامنه‌ی هر ایجنت، می‌توانیم دقت کلی آن‌ها را در پاسخ به پیام‌های کاربر افزایش دهیم.

ایجنت‌ها در LlamaIndex همچنین می‌توانند مستقیماً به‌عنوان ابزار برای ایجنت‌های دیگر استفاده شوند، برای سناریوهای پیچیده‌تر و سفارشی‌تر.

from llama_index.core.agent.workflow import (
    AgentWorkflow,
    FunctionAgent,
    ReActAgent,
)

# تعریف چند ابزار
def add(a: int, b: int) -> int:
    """Add two numbers."""
    return a + b


def subtract(a: int, b: int) -> int:
    """Subtract two numbers."""
    return a - b


# ساخت پیکربندی ایجنت‌ها
# توجه: اینجا می‌توانیم از FunctionAgent یا ReActAgent استفاده کنیم.
# FunctionAgent برای LLMهایی کار می‌کند که function calling API دارند.
# ReActAgent با هر LLMی کار می‌کند.
calculator_agent = ReActAgent(
    name="calculator",
    description="Performs basic arithmetic operations",
    system_prompt="You are a calculator assistant. Use your tools for any math operation.",
    tools=[add, subtract],
    llm=llm,
)

query_agent = ReActAgent(
    name="info_lookup",
    description="Looks up information about XYZ",
    system_prompt="Use your tool to query a RAG system to answer information about XYZ",
    tools=[query_engine_tool],
    llm=llm
)

# ساخت و اجرای گردش‌کار
agent = AgentWorkflow(
    agents=[calculator_agent, query_agent], root_agent="calculator"
)

# اجرای سیستم
response = await agent.run(user_msg="Can you add 5 and 3?")
