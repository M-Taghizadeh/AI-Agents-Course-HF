خانه/۰۲ — فریم‌ورک‌های ایجنت/LangGraph/گراف تحلیل اسناد و ReAct

گراف تحلیل اسناد (Document Analysis Graph) و الگوی ReAct

آلفرد در خدمت شماست. به‌عنوان پیشخدمت مورد اعتماد آقای وین، این اختیار را به خود دادم که نحوه‌ی کمک به ایشان در نیازهای مختلف مربوط به اسناد را مستند کنم. وقتی ایشان مشغول فعالیت‌های... شبانه‌شان هستند، من مطمئن می‌شوم همه‌ی کاغذبازی‌ها، برنامه‌های تمرینی و برنامه‌های تغذیه‌شان به‌درستی تحلیل و سازمان‌دهی می‌شود.

پیش از رفتن، ایشان یادداشتی با برنامه‌ی تمرینی هفته‌شان گذاشتند. من هم مسئولیت را به عهده گرفتم و یک منو برای وعده‌های غذایی فردا تهیه کردم.

برای چنین موقعیت‌هایی در آینده، بیایید با LangGraph یک سیستم تحلیل اسناد بسازیم که نیازهای آقای وین را برآورده کند. این سیستم می‌تواند:

  1. اسناد تصویری را پردازش کند
  2. با استفاده از مدل‌های بینایی (Vision Language Model) متن را استخراج کند
  3. در صورت نیاز محاسبات انجام دهد (برای نمایش ابزارهای معمولی)
  4. محتوا را تحلیل کند و خلاصه‌های مختصر ارائه دهد
  5. دستورالعمل‌های خاص مرتبط با اسناد را اجرا کند

تعریف State ایجنت

این State کمی پیچیده‌تر از مواردی است که تاکنون دیده‌ایم. AnyMessage کلاسی از LangChain است که پیام‌ها را تعریف می‌کند و add_messages یک عملگر (Operator) است که آخرین پیام را به تاریخچه اضافه می‌کند به‌جای اینکه آن را با آخرین وضعیت جایگزین کند.

این یک مفهوم جدید در LangGraph است که در آن می‌توانید عملگرهایی را در State خود تعریف کنید تا نحوه‌ی تعامل مقادیر با یکدیگر مشخص شود.

class AgentState(TypedDict):
    # سندی که ارائه شده است
    input_file: Optional[str]  # شامل مسیر فایل (PDF/PNG)
    messages: Annotated[list[AnyMessage], add_messages]

آماده‌سازی ابزارها

vision_llm = ChatOpenAI(model="gpt-4o")

def extract_text(img_path: str) -> str:
    """
    Extract text from an image file using a multimodal model.
    
    Master Wayne often leaves notes with his training regimen or meal plans.
    This allows me to properly analyze the contents.
    """
    all_text = ""
    try:
        # خواندن تصویر و کدگذاری آن به‌صورت base64
        with open(img_path, "rb") as image_file:
            image_bytes = image_file.read()

        image_base64 = base64.b64encode(image_bytes).decode("utf-8")

        # آماده‌سازی پرامپت شامل داده‌ی base64 تصویر
        message = [
            HumanMessage(
                content=[
                    {
                        "type": "text",
                        "text": (
                            "Extract all the text from this image. "
                            "Return only the extracted text, no explanations."
                        ),
                    },
                    {
                        "type": "image_url",
                        "image_url": {
                            "url": f"data:image/png;base64,{image_base64}"
                        },
                    },
                ]
            )
        ]

        # فراخوانی مدلی که قابلیت بینایی دارد
        response = vision_llm.invoke(message)

        # افزودن متن استخراج‌شده
        all_text += response.content + "\n\n"

        return all_text.strip()
    except Exception as e:
        # یک پیشخدمت باید خطاها را با ظرافت مدیریت کند
        error_msg = f"Error extracting text: {str(e)}"
        print(error_msg)
        return ""

def divide(a: int, b: int) -> float:
    """Divide a and b - for Master Wayne's occasional calculations."""
    return a / b

# مجهز کردن پیشخدمت به ابزارها
tools = [
    divide,
    extract_text
]

llm = ChatOpenAI(model="gpt-4o")
llm_with_tools = llm.bind_tools(tools, parallel_tool_calls=False)

نودها

def assistant(state: AgentState):
    # پیام سیستمی (System message)
    textual_description_of_tool="""
extract_text(img_path: str) -> str:
    Extract text from an image file using a multimodal model.

    Args:
        img_path: A local image file path (strings).

    Returns:
        A single string containing the concatenated text extracted from each image.
divide(a: int, b: int) -> float:
    Divide a and b
"""
    image=state["input_file"]
    sys_msg = SystemMessage(content=f"You are a helpful butler named Alfred that serves Mr. Wayne and Batman. You can analyse documents and run computations with provided tools:\n{textual_description_of_tool} \n You have access to some optional images. Currently the loaded image is: {image}")

    return {
        "messages": [llm_with_tools.invoke([sys_msg] + state["messages"])],
        "input_file": state["input_file"]
    }

الگوی ReAct: چگونه به آقای وین کمک می‌کنم

اجازه دهید رویکرد این ایجنت را توضیح دهم. این ایجنت از الگویی پیروی می‌کند که به ReAct (استدلال - عمل - مشاهده | Reason-Act-Observe) معروف است:

  1. درباره‌ی اسناد و درخواست‌های ایشان استدلال کنم (Reason)
  2. با استفاده از ابزارهای مناسب عمل کنم (Act)
  3. نتایج را مشاهده کنم (Observe)
  4. در صورت نیاز تکرار کنم تا نیازهای ایشان را به‌طور کامل برآورده کنم

این یک پیاده‌سازی ساده از یک ایجنت با LangGraph است.

# گراف
builder = StateGraph(AgentState)

# تعریف نودها: این‌ها کار اصلی را انجام می‌دهند
builder.add_node("assistant", assistant)
builder.add_node("tools", ToolNode(tools))

# تعریف یال‌ها: این‌ها تعیین می‌کنند جریان کنترل چگونه حرکت کند
builder.add_edge(START, "assistant")
builder.add_conditional_edges(
    "assistant",
    # اگر آخرین پیام به ابزار نیاز دارد، به tools مسیر بده
    # در غیر این صورت، پاسخ مستقیم بده
    tools_condition,
)
builder.add_edge("tools", "assistant")
react_graph = builder.compile()

# نمایش فرایند تفکر پیشخدمت
display(Image(react_graph.get_graph(xray=True).draw_mermaid_png()))

ما یک نود tools با فهرست ابزارهایمان تعریف می‌کنیم. نود assistant فقط همان مدل ما با ابزارهای متصل‌شده (Bound Tools) است. گرافی با نودهای assistant و tools می‌سازیم.

یک یال tools_condition اضافه می‌کنیم که بر اساس اینکه assistant ابزاری را فراخوانی کند یا نه، به END یا به tools مسیر می‌دهد.

اکنون یک گام جدید اضافه می‌کنیم:

نود tools را دوباره به assistant وصل می‌کنیم و یک حلقه می‌سازیم.

  • پس از اجرای نود assistant، tools_condition بررسی می‌کند که آیا خروجی مدل یک فراخوانی ابزار (Tool Call) است یا نه.
  • اگر فراخوانی ابزار باشد، جریان به نود tools هدایت می‌شود.
  • نود tools دوباره به assistant متصل می‌شود.
  • این حلقه تا زمانی ادامه می‌یابد که مدل تصمیم به فراخوانی ابزار بگیرد.
  • اگر پاسخ مدل فراخوانی ابزار نباشد، جریان به END هدایت می‌شود و فرایند پایان می‌یابد.

پیشخدمت در عمل

مثال ۱: محاسبات ساده

این یک مثال برای نمایش یک کاربرد ساده از ایجنتی است که در LangGraph از یک ابزار استفاده می‌کند.

messages = [HumanMessage(content="Divide 6790 by 5")]
messages = react_graph.invoke({"messages": messages, "input_file": None})

# نمایش پیام‌ها
for m in messages['messages']:
    m.pretty_print()

مکالمه به این شکل پیش می‌رود:

Human: Divide 6790 by 5

AI Tool Call: divide(a=6790, b=5)

Tool Response: 1358.0

Alfred: The result of dividing 6790 by 5 is 1358.0.

مثال ۲: تحلیل اسناد تمرینی استاد وین

وقتی استاد وین یادداشت‌های تمرین و برنامه‌ی غذایی‌شان را می‌گذارند:

messages = [HumanMessage(content="According to the note provided by Mr. Wayne in the provided images. What's the list of items I should buy for the dinner menu?")]
messages = react_graph.invoke({"messages": messages, "input_file": "Batman_training_and_meals.png"})

تعامل به این شکل پیش می‌رود:

Human: According to the note provided by Mr. Wayne in the provided images. What's the list of items I should buy for the dinner menu?

AI Tool Call: extract_text(img_path="Batman_training_and_meals.png")

Tool Response: [Extracted text with training schedule and menu details]

Alfred: For the dinner menu, you should buy the following items:

1. Grass-fed local sirloin steak
2. Organic spinach
3. Piquillo peppers
4. Potatoes (for oven-baked golden herb potato)
5. Fish oil (2 grams)

Ensure the steak is grass-fed and the spinach and peppers are organic for the best quality meal.

نکات کلیدی

اگر مایل باشید پیشخدمت تحلیل اسناد خودتان را بسازید، نکات مهم زیر را در نظر بگیرید:

  1. ابزارهای مشخص تعریف کنید برای وظایف خاص مرتبط با اسناد
  2. یک ردیاب State مقاوم بسازید تا زمینه (Context) بین فراخوانی‌های ابزار حفظ شود
  3. مدیریت خطا را در نظر بگیرید برای زمانی که ابزارها شکست می‌خورند
  4. آگاهی زمینه‌ای از تعاملات قبلی را حفظ کنید (که توسط عملگر add_messages تضمین می‌شود)

با این اصول، شما هم می‌توانید سرویس تحلیل اسنادی در خور عمارت وین ارائه دهید.
