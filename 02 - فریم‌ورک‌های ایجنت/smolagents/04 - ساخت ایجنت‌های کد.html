خانه/۰۲.۱ — فریم‌ورک smolagents/ساخت ایجنت‌های کد

📓 اجرا در Google Colab · 💬 کمک گرفتن در دیسکورد

ساخت ایجنت‌هایی که از کد استفاده می‌کنند

ایجنت‌های کد (Code Agents) نوع پیش‌فرض ایجنت در smolagents هستند. آن‌ها برای انجام اکشن‌ها فراخوانی‌های ابزار را به صورت کد پایتون تولید می‌کنند و به نمایش‌هایی از اکشن می‌رسند که کارآمد، گویا و دقیق است.

رویکرد ساده آن‌ها تعداد اکشن‌های لازم را کاهش می‌دهد، عملیات پیچیده را ساده می‌کند و امکان استفاده مجدد از توابع موجود را فراهم می‌سازد. smolagents یک فریم‌ورک سبک برای ساخت ایجنت‌های کد ارائه می‌دهد که در حدود ۱۰۰۰ خط کد پیاده شده است.

تصویر از مقاله Executable Code Actions Elicit Better LLM Agents

نکته: اگر می‌خواهید بیشتر درباره دلیل اثربخشی ایجنت‌های کد بدانید، این راهنما را در مستندات smolagents ببینید.

چرا ایجنت‌های کد؟

در یک فرایند ایجنتی چندمرحله‌ای، LLM اکشن‌ها را که معمولاً شامل فراخوانی ابزارهای خارجی است می‌نویسد و اجرا می‌کند. رویکردهای سنتی از قالب JSON برای مشخص کردن نام ابزار و آرگومان‌ها به صورت رشته استفاده می‌کنند، که سیستم باید آن‌ها را پارس کند تا بفهمد کدام ابزار را اجرا کند.

با این حال، پژوهش‌ها نشان می‌دهد LLMهای فراخوان‌کننده ابزار وقتی مستقیماً با کد کار کنند مؤثرتر عمل می‌کنند. این یک اصل بنیادین smolagents است، همان‌طور که در نمودار بالا از مقاله Executable Code Actions Elicit Better LLM Agents می‌بینید.

نوشتن اکشن‌ها به صورت کد به جای JSON مزایای کلیدی متعددی دارد:

  • ترکیب‌پذیری (Composability): ترکیب و استفاده مجدد از اکشن‌ها به‌سادگی ممکن است.
  • مدیریت اشیا (Object Management): کار مستقیم با ساختارهای پیچیده مانند تصاویر.
  • عمومیت (Generality): بیان هر کار قابل محاسبه.
  • طبیعی بودن برای LLMها: کد باکیفیت پیش‌تر در داده‌های آموزشی LLMها وجود دارد.

یک ایجنت کد چگونه کار می‌کند؟

نمودار بالا نشان می‌دهد CodeAgent.run() چگونه کار می‌کند و از چارچوب ReAct که در واحد ۱ اشاره کردیم پیروی می‌کند. انتزاع اصلی ایجنت‌ها در smolagents کلاس MultiStepAgent است که بلوک سازنده هسته‌ای به شمار می‌رود. همان‌طور که در مثالی در ادامه می‌بینیم، CodeAgent نوع خاصی از MultiStepAgent است.

یک CodeAgent اکشن‌ها را در قالب چرخه‌ای از مراحل انجام می‌دهد؛ در این چرخه متغیرها و دانش موجود به زمینه (context) ایجنت اضافه می‌شوند و در یک لاگ اجرا نگه‌داری می‌شوند:

  1. پرامپت سیستم در یک SystemPromptStep ذخیره و پرسش کاربر در یک TaskStep ثبت می‌شود.
  2. سپس حلقه while زیر اجرا می‌شود:
    1. متد agent.write_memory_to_messages() لاگ‌های ایجنت را در فهرستی از پیام‌های چت قابل خواندن برای LLM می‌نویسد.
    2. این پیام‌ها به یک Model فرستاده می‌شوند که یک تکمیل (completion) تولید می‌کند.
    3. تکمیل پارس می‌شود تا اکشن استخراج شود؛ در مورد ما چون با CodeAgent کار می‌کنیم، این اکشن باید یک قطعه‌کد باشد.
    4. اکشن اجرا می‌شود.
    5. نتایج در حافظه و در یک ActionStep ثبت می‌شوند.

در پایان هر مرحله، اگر ایجنت فراخوانی تابعی داشته باشد (در agent.step_callback)، آن‌ها اجرا می‌شوند.

بیایید چند مثال ببینیم

نکته: می‌توانید کد را در این نوت‌بوک که با Google Colab قابل اجراست دنبال کنید.

آلفرد در حال برنامه‌ریزی یک مهمانی در عمارت خانواده وین است و برای اینکه همه‌چیز بی‌نقص پیش برود به کمک شما نیاز دارد. برای کمک به او، آنچه درباره نحوه کار یک CodeAgent چندمرحله‌ای آموختیم به کار می‌بریم.

اگر هنوز smolagents را نصب نکرده‌اید، با دستور زیر نصب کنید:

pip install smolagents -U

همچنین برای دسترسی به Serverless Inference API وارد Hugging Face Hub می‌شویم:

انتخاب پلی‌لیست مهمانی با smolagents

موسیقی بخش اساسی یک مهمانی موفق است! آلفرد برای انتخاب پلی‌لیست به کمک نیاز دارد. خوشبختانه smolagents کنارمان است! می‌توانیم ایجنتی بسازیم که با DuckDuckGo در وب جستجو کند. برای اینکه ایجنت به این ابزار دسترسی داشته باشد، هنگام ساخت ایجنت آن را در فهرست ابزارها قرار می‌دهیم.

برای مدل از InferenceClientModel استفاده می‌کنیم که دسترسی به Serverless Inference API شرکت Hugging Face را فراهم می‌کند. مدل پیش‌فرض "Qwen/Qwen2.5-Coder-32B-Instruct" است که کارآمد است و برای استنتاج سریع در دسترس قرار دارد، اما می‌توانید هر مدل سازگار دیگری را از Hub انتخاب کنید.

اجرای یک ایجنت کاملاً ساده است:

from smolagents import CodeAgent, DuckDuckGoSearchTool, InferenceClientModel

agent = CodeAgent(tools=[DuckDuckGoSearchTool()], model=InferenceClientModel())

agent.run("Search for the best music recommendations for a party at the Wayne's mansion.")

وقتی این مثال را اجرا کنید، خروجی ردی از مراحل اجرای گردش کار را نمایش می‌دهد. همچنین کد پایتون متناظر را با این پیام چاپ می‌کند:

 ─ Executing parsed code: ──────────────────────────────────────────────────────────────────────────────────────── 
  results = web_search(query="best music for a Batman party")                                                      
  print(results)                                                                                                   
 ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────

پس از چند مرحله، پلی‌لیست تولیدشده را می‌بینید که آلفرد می‌تواند در مهمانی استفاده کند! 🎵

استفاده از یک ابزار سفارشی برای تهیه منو

حالا که پلی‌لیست را انتخاب کردیم، باید منوی مهمانان را سازماندهی کنیم. آلفرد باز هم می‌تواند از smolagents کمک بگیرد. اینجا با دکوراتور @tool یک تابع سفارشی تعریف می‌کنیم که نقش ابزار را دارد. ساخت ابزار را بعداً با جزئیات بیشتری پوشش می‌دهیم؛ فعلاً کافی است کد را اجرا کنیم.

همان‌طور که در مثال زیر می‌بینید، با دکوراتور @tool یک ابزار می‌سازیم و آن را در فهرست tools قرار می‌دهیم.

from smolagents import CodeAgent, tool, InferenceClientModel

# Tool to suggest a menu based on the occasion
@tool
def suggest_menu(occasion: str) -> str:
    """
    Suggests a menu based on the occasion.
    Args:
        occasion (str): The type of occasion for the party. Allowed values are:
                        - "casual": Menu for casual party.
                        - "formal": Menu for formal party.
                        - "superhero": Menu for superhero party.
                        - "custom": Custom menu.
    """
    if occasion == "casual":
        return "Pizza, snacks, and drinks."
    elif occasion == "formal":
        return "3-course dinner with wine and dessert."
    elif occasion == "superhero":
        return "Buffet with high-energy and healthy food."
    else:
        return "Custom menu for the butler."

# Alfred, the butler, preparing the menu for the party
agent = CodeAgent(tools=[suggest_menu], model=InferenceClientModel())

# Preparing the menu for the party
agent.run("Prepare a formal menu for the party.")

ایجنت چند مرحله اجرا می‌شود تا پاسخ را پیدا کند. مشخص کردن مقادیر مجاز در docstring به ایجنت کمک می‌کند آرگومان occasion را با مقادیر موجود پر کند و توهم (hallucination) را محدود می‌کند.

منو آماده است! 🥗

استفاده از import در پایتون داخل ایجنت

پلی‌لیست و منو آماده‌اند، اما یک جزئیات حیاتی دیگر مانده که باید بررسی کنیم: زمان آماده‌سازی!

آلفرد باید محاسبه کند اگر همین الان آماده‌سازی را شروع کند، همه‌چیز چه ساعتی آماده می‌شود؛ مخصوصاً اگر به کمک سایر ابرقهرمانان نیاز پیدا کنند.

smolagents در ایجنت‌هایی تخصص دارد که قطعه‌کدهای پایتون را می‌نویسند و اجرا می‌کنند، و برای امنیت، اجرای ایزوله (sandboxed) ارائه می‌دهد.

اجرای کد دارای تدابیر امنیتی سخت‌گیرانه است ــ importهای خارج از یک فهرست امن از پیش تعریف‌شده به صورت پیش‌فرض مسدود هستند. با این حال می‌توانید importهای اضافی را با ارسال آن‌ها به صورت رشته در additional_authorized_imports مجاز کنید. برای جزئیات بیشتر درباره اجرای امن کد، راهنمای رسمی را ببینید.

هنگام ساخت ایجنت، با additional_authorized_imports اجازه import ماژول datetime را می‌دهیم.

from smolagents import CodeAgent, InferenceClientModel
import numpy as np
import time
import datetime

agent = CodeAgent(tools=[], model=InferenceClientModel(), additional_authorized_imports=['datetime'])

agent.run(
    """
    Alfred needs to prepare for the party. Here are the tasks:
    1. Prepare the drinks - 30 minutes
    2. Decorate the mansion - 60 minutes
    3. Set up the menu - 45 minutes
    4. Prepare the music and playlist - 45 minutes

    If we start right now, at what time will the party be ready?
    """
)

این مثال‌ها فقط آغاز کار با ایجنت‌های کد هستند و همین حالا هم مفید بودنشان را در آماده‌سازی مهمانی می‌بینیم. برای آموختن بیشتر درباره ساخت ایجنت‌های کد می‌توانید به مستندات smolagents مراجعه کنید.

در مجموع، smolagents در ایجنت‌هایی تخصص دارد که قطعه‌کدهای پایتون را می‌نویسند و اجرا می‌کنند و برای امنیت، اجرای ایزوله ارائه می‌دهد. این کتابخانه هم از مدل‌های زبانی محلی و هم مبتنی بر API پشتیبانی می‌کند و با محیط‌های توسعه گوناگون سازگار است.

اشتراک‌گذاری ایجنت «آماده‌ساز مهمانی» ما در Hub

آیا اشتراک‌گذاری ایجنت آلفرد با جامعه فوق‌العاده نیست؟ با این کار هر کسی می‌تواند ایجنت را مستقیماً از Hub دانلود و استفاده کند و بهترین برنامه‌ریز مهمانی گاتهام را در اختیار داشته باشد! بیایید این کار را انجام دهیم! 🎉

کتابخانه smolagents این امکان را می‌دهد که یک ایجنت کامل را با جامعه به اشتراک بگذارید و ایجنت‌های دیگران را برای استفاده فوری دانلود کنید. به سادگی زیر:

# Change to your username and repo name
agent.push_to_hub('sergiopaniego/AlfredAgent')

برای دانلود دوباره ایجنت، از کد زیر استفاده کنید:

# Change to your username and repo name
alfred_agent = agent.from_hub('sergiopaniego/AlfredAgent', trust_remote_code=True)

alfred_agent.run("Give me the best playlist for a party at Wayne's mansion. The party idea is a 'villain masquerade' theme")

نکته جالب دیگر اینکه ایجنت‌های به اشتراک گذاشته‌شده مستقیماً به صورت Hugging Face Space در دسترس‌اند و می‌توانید به‌صورت بلادرنگ با آن‌ها تعامل کنید. می‌توانید ایجنت‌های دیگر را اینجا ببینید.

برای مثال، AlfredAgent اینجا در دسترس است. می‌توانید مستقیماً در پایین امتحانش کنید:

شاید بپرسید آلفرد چگونه چنین ایجنتی را با smolagents ساخته است؟ او با ادغام چند ابزار می‌تواند ایجنت را به صورت زیر بسازد. فعلاً نگران ابزارها نباشید، چون بعداً در همین واحد بخش جداگانه‌ای برای بررسی دقیق آن‌ها داریم:

from smolagents import CodeAgent, DuckDuckGoSearchTool, FinalAnswerTool, InferenceClientModel, Tool, tool, VisitWebpageTool

@tool
def suggest_menu(occasion: str) -> str:
    """
    Suggests a menu based on the occasion.
    Args:
        occasion: The type of occasion for the party.
    """
    if occasion == "casual":
        return "Pizza, snacks, and drinks."
    elif occasion == "formal":
        return "3-course dinner with wine and dessert."
    elif occasion == "superhero":
        return "Buffet with high-energy and healthy food."
    else:
        return "Custom menu for the butler."

@tool
def catering_service_tool(query: str) -> str:
    """
    This tool returns the highest-rated catering service in Gotham City.
    
    Args:
        query: A search term for finding catering services.
    """
    # Example list of catering services and their ratings
    services = {
        "Gotham Catering Co.": 4.9,
        "Wayne Manor Catering": 4.8,
        "Gotham City Events": 4.7,
    }
    
    # Find the highest rated catering service (simulating search query filtering)
    best_service = max(services, key=services.get)
    
    return best_service

class SuperheroPartyThemeTool(Tool):
    name = "superhero_party_theme_generator"
    description = """
    This tool suggests creative superhero-themed party ideas based on a category.
    It returns a unique party theme idea."""
    
    inputs = {
        "category": {
            "type": "string",
            "description": "The type of superhero party (e.g., 'classic heroes', 'villain masquerade', 'futuristic Gotham').",
        }
    }
    
    output_type = "string"

    def forward(self, category: str):
        themes = {
            "classic heroes": "Justice League Gala: Guests come dressed as their favorite DC heroes with themed cocktails like 'The Kryptonite Punch'.",
            "villain masquerade": "Gotham Rogues' Ball: A mysterious masquerade where guests dress as classic Batman villains.",
            "futuristic gotham": "Neo-Gotham Night: A cyberpunk-style party inspired by Batman Beyond, with neon decorations and futuristic gadgets."
        }
        
        return themes.get(category.lower(), "Themed party idea not found. Try 'classic heroes', 'villain masquerade', or 'futuristic Gotham'.")


# Alfred, the butler, preparing the menu for the party
agent = CodeAgent(
    tools=[
        DuckDuckGoSearchTool(), 
        VisitWebpageTool(),
        suggest_menu,
        catering_service_tool,
        SuperheroPartyThemeTool(),
	FinalAnswerTool()
    ], 
    model=InferenceClientModel(),
    max_steps=10,
    verbosity_level=2
)

agent.run("Give me the best playlist for a party at the Wayne's mansion. The party idea is a 'villain masquerade' theme")

همان‌طور که می‌بینید، یک CodeAgent با چند ابزار ساخته‌ایم که قابلیت‌های ایجنت را افزایش می‌دهند و آن را به برنامه‌ریز نهایی مهمانی تبدیل می‌کنند که آماده اشتراک‌گذاری با جامعه است! 🎉

بازرسی ایجنت آماده‌ساز مهمانی با OpenTelemetry و Langfuse 📡

همان‌طور که آلفرد ایجنت آماده‌ساز مهمانی را بهبود می‌دهد، از دیباگ کردن اجراهایش خسته می‌شود. ایجنت‌ها ذاتاً غیرقابل‌پیش‌بینی هستند و بازرسی‌شان دشوار است. اما چون او می‌خواهد بهترین ایجنت آماده‌ساز مهمانی را بسازد و در محیط عملیاتی (production) مستقر کند، برای پایش و تحلیل‌های آینده به ردیابی‌پذیری (traceability) مطمئن نیاز دارد.

باز هم smolagents به کمک می‌آید! این کتابخانه استاندارد OpenTelemetry را برای ابزارگذاری (instrumentation) اجرای ایجنت‌ها پشتیبانی می‌کند و بازرسی و ثبت روان را ممکن می‌سازد. با کمک Langfuse و SmolagentsInstrumentor، آلفرد می‌تواند به‌آسانی رفتار ایجنتش را ردیابی و تحلیل کند.

راه‌اندازی آن ساده است!

ابتدا باید وابستگی‌های لازم را نصب کنیم:

pip install opentelemetry-sdk opentelemetry-exporter-otlp openinference-instrumentation-smolagents langfuse

سپس، آلفرد پیش‌تر در Langfuse حساب ساخته و کلیدهای API‌اش را آماده دارد. اگر هنوز این کار را نکرده‌اید، می‌توانید اینجا در Langfuse Cloud ثبت‌نام کنید یا جایگزین‌ها را بررسی کنید.

پس از دریافت کلیدهای API، باید آن‌ها را به صورت زیر پیکربندی کنید:

import os

# Get keys for your project from the project settings page: https://cloud.langfuse.com
os.environ["LANGFUSE_PUBLIC_KEY"] = "pk-lf-..." 
os.environ["LANGFUSE_SECRET_KEY"] = "sk-lf-..." 
os.environ["LANGFUSE_HOST"] = "https://cloud.langfuse.com" # 🇪🇺 EU region
# os.environ["LANGFUSE_HOST"] = "https://us.cloud.langfuse.com" # 🇺🇸 US region

با تنظیم متغیرهای محیطی، حالا می‌توانیم کلاینت Langfuse را مقداردهی اولیه کنیم. get_client() کلاینت Langfuse را با اعتبارنامه‌های موجود در متغیرهای محیطی راه‌اندازی می‌کند.

from langfuse import get_client
 
langfuse = get_client()
 
# Verify connection
if langfuse.auth_check():
    print("Langfuse client is authenticated and ready!")
else:
    print("Authentication failed. Please check your credentials and host.")

در نهایت، آلفرد آماده است SmolagentsInstrumentor را مقداردهی اولیه کند و ردیابی عملکرد ایجنتش را آغاز کند.

from openinference.instrumentation.smolagents import SmolagentsInstrumentor

SmolagentsInstrumentor().instrument()

آلفرد حالا متصل است 🔌! اجراهای smolagents در Langfuse ثبت می‌شوند و دید کاملی از رفتار ایجنت به او می‌دهند. با این پیکربندی، او آماده است اجراهای قبلی را مرور کند و ایجنت آماده‌ساز مهمانی‌اش را باز هم بهبود دهد.

نکته: برای آموختن بیشتر درباره ردیابی ایجنت‌ها و استفاده از داده‌های جمع‌آوری‌شده برای ارزیابی عملکردشان، واحد جایزه ۲ را ببینید.

from smolagents import CodeAgent, InferenceClientModel

agent = CodeAgent(tools=[], model=InferenceClientModel())
alfred_agent = agent.from_hub('sergiopaniego/AlfredAgent', trust_remote_code=True)
alfred_agent.run("Give me the best playlist for a party at Wayne's mansion. The party idea is a 'villain masquerade' theme")

آلفرد حالا می‌تواند این لاگ‌ها را اینجا مرور و تحلیل کند.

نکته: در واقع هنگام اجرا یک خطای کوچک رخ داده است. می‌توانید آن را در لاگ‌ها پیدا کنید؟ سعی کنید ردیابی کنید ایجنت چگونه آن را مدیریت می‌کند و همچنان پاسخی معتبر برمی‌گرداند. اینجا لینک مستقیم خطا برای راستی‌آزمایی پاسخ شماست. البته این خطا در این فاصله رفع شده است؛ جزئیات بیشتر در این issue آمده است.

در همین حال، پلی‌لیست پیشنهادی حال‌وهوای عالی‌ای برای آماده‌سازی مهمانی می‌سازد. جالب است، نه؟ 🎶

حالا که اولین ایجنت کد خود را ساختیم، بیایید یاد بگیریم چگونه ایجنت‌های فراخوان ابزار بسازیم، یعنی نوع دوم ایجنت موجود در smolagents.
