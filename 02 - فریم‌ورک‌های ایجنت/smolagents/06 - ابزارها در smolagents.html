📓 اجرا در Google Colab · 💬 کمک گرفتن در دیسکورد

ابزارها (Tools)

همان‌طور که در واحد ۱ دیدیم، ایجنت‌ها برای انجام اکشن‌های گوناگون از ابزارها استفاده می‌کنند. در smolagents ابزارها به عنوان توابعی که یک LLM می‌تواند درون یک سیستم ایجنتی فراخوانی کند در نظر گرفته می‌شوند.

برای تعامل با یک ابزار، LLM به یک توضیح رابط (interface description) با اجزای کلیدی زیر نیاز دارد:

  • نام (Name): ابزار چه نامی دارد
  • توضیح ابزار (Tool description): ابزار چه کاری می‌کند
  • انواع و توضیحات ورودی: ابزار چه آرگومان‌هایی می‌پذیرد
  • نوع خروجی (Output type): ابزار چه چیزی برمی‌گرداند

برای مثال، در آماده‌سازی مهمانی عمارت وین، آلفرد به ابزارهای مختلفی برای جمع‌آوری اطلاعات نیاز دارد ــ از جستجوی خدمات کترینگ تا یافتن ایده‌های تم مهمانی. رابط یک ابزار جستجوی ساده می‌تواند این شکل باشد:

  • نام: web_search
  • توضیح ابزار: جستجوی وب برای پرسش‌های مشخص
  • ورودی: query (رشته) — عبارت جستجو
  • خروجی: رشته‌ای شامل نتایج جستجو

آلفرد با استفاده از این ابزارها می‌تواند تصمیم‌های آگاهانه بگیرد و همه اطلاعات لازم برای برنامه‌ریزی مهمانی بی‌نقص را جمع کند.

در پایین، انیمیشنی می‌بینید که نشان می‌دهد یک فراخوانی ابزار چگونه مدیریت می‌شود:

منبع تصویر: مستندات smolagents

روش‌های ساخت ابزار

در smolagents ابزارها را می‌توان به دو روش تعریف کرد:

  1. استفاده از دکوراتور @tool برای ابزارهای ساده مبتنی بر تابع
  2. ساخت زیرکلاس از Tool برای قابلیت‌های پیچیده‌تر

دکوراتور @tool

دکوراتور @tool روش توصیه‌شده برای تعریف ابزارهای ساده است. در پشت صحنه، smolagents اطلاعات پایه تابع را از پایتون پارس می‌کند. بنابراین اگر نام تابع را واضح انتخاب کنید و docstring خوبی بنویسید، استفاده از آن برای LLM آسان‌تر می‌شود.

در این روش، تابعی تعریف می‌کنیم که دارای این ویژگی‌هاست:

  • نام تابع واضح و توصیفی که به LLM کمک می‌کند هدف آن را بفهمد.
  • نوع‌نما (type hint) برای ورودی‌ها و خروجی‌ها تا استفاده درست تضمین شود.
  • توضیح دقیق شامل بخش Args: که در آن هر آرگومان صراحتاً توصیف می‌شود. این توضیحات زمینه ارزشمندی برای LLM فراهم می‌کنند، پس مهم است که با دقت نوشته شوند.

ساخت ابزاری که کترینگ با بالاترین امتیاز را پیدا می‌کند

نکته: می‌توانید کد را در این نوت‌بوک که با Google Colab قابل اجراست دنبال کنید.

فرض کنید آلفرد منوی مهمانی را تعیین کرده، اما حالا برای تهیه غذا برای این تعداد زیاد مهمان به کمک نیاز دارد. او می‌خواهد یک سرویس کترینگ استخدام کند و باید گزینه‌های با بالاترین امتیاز را شناسایی کند. آلفرد می‌تواند با ابزاری، بهترین سرویس‌های کترینگ منطقه‌اش را جستجو کند.

در ادامه نمونه‌ای از نحوه استفاده آلفرد از دکوراتور @tool برای این کار را می‌بینید:

from smolagents import CodeAgent, InferenceClientModel, tool

# Let's pretend we have a function that fetches the highest-rated catering services.
@tool
def catering_service_tool(query: str) -> str:
    """
    This tool returns the highest-rated catering service in Gotham City.

    Args:
        query: A search term for finding catering services.
    """
    # Example list of catering services and their ratings
    services = {
        "Gotham Catering Co.": 4.9,
        "Wayne Manor Catering": 4.8,
        "Gotham City Events": 4.7,
    }

    # Find the highest rated catering service (simulating search query filtering)
    best_service = max(services, key=services.get)

    return best_service


agent = CodeAgent(tools=[catering_service_tool], model=InferenceClientModel())

# Run the agent to find the best catering service
result = agent.run(
    "Can you give me the name of the highest-rated catering service in Gotham City?"
)

print(result)   # Output: Gotham Catering Co.

تعریف ابزار به صورت یک کلاس پایتون

این رویکرد شامل ساخت زیرکلاسی از Tool است. برای ابزارهای پیچیده می‌توانیم به جای تابع، یک کلاس پیاده کنیم. کلاس، تابع را با فراداده‌هایی (metadata) می‌پوشاند که به LLM کمک می‌کند ابزار را مؤثرتر به کار ببرد. در این کلاس تعریف می‌کنیم:

  • name: نام ابزار.
  • description: توضیحی که برای پر کردن پرامپت سیستم ایجنت استفاده می‌شود.
  • inputs: دیکشنری‌ای با کلیدهای type و description که اطلاعاتی برای کمک به مفسر پایتون در پردازش ورودی‌ها فراهم می‌کند.
  • output_type: نوع خروجی مورد انتظار را مشخص می‌کند.
  • forward: متدی که منطق استنتاج (اجرای ابزار) را در بر دارد.

در ادامه مثالی از ابزاری که با Tool ساخته شده و نحوه ادغام آن در یک CodeAgent را می‌بینید.

ساخت ابزاری برای تولید ایده‌های مهمانی با تم ابرقهرمانی

مهمانی آلفرد در عمارت یک رویداد با تم ابرقهرمانی است، اما او برای اینکه آن را واقعاً خاص کند به ایده‌های خلاقانه نیاز دارد. به عنوان یک میزبان فوق‌العاده، می‌خواهد مهمانان را با یک تم منحصربه‌فرد شگفت‌زده کند.

برای این کار می‌تواند از ایجنتی استفاده کند که بر اساس یک دسته‌بندی مشخص، ایده‌های مهمانی با تم ابرقهرمانی تولید می‌کند. به این ترتیب آلفرد می‌تواند تم مناسب را پیدا کند و مهمانانش را شگفت‌زده کند.

from smolagents import Tool, CodeAgent, InferenceClientModel

class SuperheroPartyThemeTool(Tool):
    name = "superhero_party_theme_generator"
    description = """
    This tool suggests creative superhero-themed party ideas based on a category.
    It returns a unique party theme idea."""

    inputs = {
        "category": {
            "type": "string",
            "description": "The type of superhero party (e.g., 'classic heroes', 'villain masquerade', 'futuristic Gotham').",
        }
    }

    output_type = "string"

    def forward(self, category: str):
        themes = {
            "classic heroes": "Justice League Gala: Guests come dressed as their favorite DC heroes with themed cocktails like 'The Kryptonite Punch'.",
            "villain masquerade": "Gotham Rogues' Ball: A mysterious masquerade where guests dress as classic Batman villains.",
            "futuristic Gotham": "Neo-Gotham Night: A cyberpunk-style party inspired by Batman Beyond, with neon decorations and futuristic gadgets."
        }

        return themes.get(category.lower(), "Themed party idea not found. Try 'classic heroes', 'villain masquerade', or 'futuristic Gotham'.")

# Instantiate the tool
party_theme_tool = SuperheroPartyThemeTool()
agent = CodeAgent(tools=[party_theme_tool], model=InferenceClientModel())

# Run the agent to generate a party theme idea
result = agent.run(
    "What would be a good superhero party idea for a 'villain masquerade' theme?"
)

print(result)  # Output: "Gotham Rogues' Ball: A mysterious masquerade where guests dress as classic Batman villains."

با این ابزار، آلفرد به ابَرمیزبانی تبدیل می‌شود که با مهمانی ابرقهرمانی فراموش‌نشدنی‌اش مهمانان را تحت تأثیر قرار می‌دهد! 🦸‍♂️🦸‍♀️

جعبه‌ابزار پیش‌فرض

smolagents مجموعه‌ای از ابزارهای از پیش ساخته‌شده دارد که می‌توان مستقیماً به ایجنت تزریق کرد. جعبه‌ابزار پیش‌فرض شامل این موارد است:

  • PythonInterpreterTool
  • FinalAnswerTool
  • UserInputTool
  • DuckDuckGoSearchTool
  • GoogleSearchTool
  • VisitWebpageTool

آلفرد می‌تواند برای تضمین یک مهمانی بی‌نقص در عمارت وین از ابزارهای مختلفی استفاده کند:

  • اول، می‌تواند از DuckDuckGoSearchTool برای یافتن ایده‌های خلاقانه مهمانی با تم ابرقهرمانی استفاده کند.
  • برای کترینگ، به GoogleSearchTool تکیه می‌کند تا سرویس‌های با بالاترین امتیاز را در گاتهام پیدا کند.
  • برای مدیریت چیدمان صندلی‌ها، آلفرد می‌تواند محاسبات را با PythonInterpreterTool اجرا کند.
  • پس از جمع‌آوری همه‌چیز، برنامه را با FinalAnswerTool تدوین می‌کند.

با این ابزارها، آلفرد تضمین می‌کند که مهمانی هم استثنایی و هم روان باشد. 🦇💡

اشتراک‌گذاری و وارد کردن ابزارها

یکی از قدرتمندترین ویژگی‌های smolagents توانایی اشتراک‌گذاری ابزارهای سفارشی در Hub و یکپارچه‌سازی روان ابزارهای ساخته‌شده توسط جامعه است. این شامل اتصال به HF Spaces و ابزارهای LangChain می‌شود و توانایی آلفرد را برای سازماندهی یک مهمانی فراموش‌نشدنی در عمارت وین به‌طور چشمگیری افزایش می‌دهد. 🎭

با این یکپارچه‌سازی‌ها، آلفرد می‌تواند به ابزارهای پیشرفته برنامه‌ریزی رویداد دسترسی پیدا کند ــ چه تنظیم نورپردازی برای حال‌وهوای عالی، چه انتخاب پلی‌لیست ایده‌آل مهمانی، و چه هماهنگی با بهترین کترینگ‌های گاتهام.

در ادامه نمونه‌هایی از این قابلیت‌ها و نحوه ارتقای تجربه مهمانی با آن‌ها را می‌بینید:

اشتراک‌گذاری یک ابزار در Hub

اشتراک‌گذاری ابزار سفارشی با جامعه آسان است! کافی است با متد push_to_hub() آن را در حساب Hugging Face خود آپلود کنید.

برای مثال، آلفرد می‌تواند party_theme_tool خود را به اشتراک بگذارد تا به دیگران در یافتن بهترین خدمات کترینگ گاتهام کمک کند. روش انجام آن:

party_theme_tool.push_to_hub("{your_username}/party_theme_tool", token="<YOUR_HUGGINGFACEHUB_API_TOKEN>")

وارد کردن یک ابزار از Hub

می‌توانید با تابع load_tool() به‌آسانی ابزارهای ساخته‌شده توسط کاربران دیگر را وارد کنید. برای مثال، آلفرد ممکن است بخواهد با هوش مصنوعی یک تصویر تبلیغاتی برای مهمانی تولید کند. به جای ساختن ابزار از صفر، می‌تواند از ابزار از پیش تعریف‌شده جامعه استفاده کند:

from smolagents import load_tool, CodeAgent, InferenceClientModel

image_generation_tool = load_tool(
    "m-ric/text-to-image",
    trust_remote_code=True
)

agent = CodeAgent(
    tools=[image_generation_tool],
    model=InferenceClientModel()
)

agent.run("Generate an image of a luxurious superhero-themed party at Wayne Manor with made-up superheros.")

وارد کردن یک Hugging Face Space به عنوان ابزار

همچنین می‌توانید با Tool.from_space() یک HF Space را به عنوان ابزار وارد کنید. این کار امکان یکپارچه‌سازی با هزاران Space جامعه را برای کارهایی از تولید تصویر تا تحلیل داده فراهم می‌کند.

این ابزار با استفاده از gradio_client به بک‌اند Gradio آن Space متصل می‌شود، پس اگر هنوز نصب نکرده‌اید حتماً آن را با pip نصب کنید.

برای مهمانی، آلفرد می‌تواند از یک HF Space موجود برای تولید تصویر هوش مصنوعی مورد استفاده در اطلاعیه استفاده کند (به جای ابزار از پیش ساخته‌ای که قبلاً ذکر شد). بیایید آن را بسازیم!

from smolagents import CodeAgent, InferenceClientModel, Tool

image_generation_tool = Tool.from_space(
    "black-forest-labs/FLUX.1-schnell",
    name="image_generator",
    description="Generate an image from a prompt"
)

model = InferenceClientModel("Qwen/Qwen2.5-Coder-32B-Instruct")

agent = CodeAgent(tools=[image_generation_tool], model=model)

agent.run(
    "Improve this prompt, then generate an image of it.",
    additional_args={'user_prompt': 'A grand superhero-themed party at Wayne Manor, with Alfred overseeing a luxurious gala'}
)

وارد کردن یک ابزار LangChain

درباره فریم‌ورک LangChain در بخش‌های بعدی صحبت خواهیم کرد. فعلاً فقط اشاره می‌کنیم که می‌توانید ابزارهای LangChain را در گردش کار smolagents خود استفاده کنید!

با متد Tool.from_langchain() به‌راحتی می‌توانید ابزارهای LangChain را بارگذاری کنید. آلفرد، که همیشه کمال‌گراست، در حال آماده‌سازی یک شب ابرقهرمانی خیره‌کننده در عمارت وین است، در حالی که خانواده وین در سفرند. برای اینکه مطمئن شود هر جزئیات از انتظارات فراتر می‌رود، از ابزارهای LangChain برای یافتن ایده‌های سرگرمی در سطح عالی استفاده می‌کند.

آلفرد با Tool.from_langchain() به‌راحتی قابلیت‌های جستجوی پیشرفته را به smolagent خود اضافه می‌کند و با چند فرمان ساده می‌تواند ایده‌ها و خدمات مهمانی انحصاری را کشف کند.

روش کار او به این صورت است:

ابتدا باید یکپارچه‌سازی langchain برای smolagents را نصب کنیم.

pip install -U langchain-community

پس از نصب یکپارچه‌سازی langchain، حتماً کلید SerpAPI خود را تنظیم کنید. این کار برای ابزارهای مبتنی بر جستجو مانند SerpAPITool لازم است:

os.environ['SERPAPI_API_KEY'] = '...'

می‌توانید کلید SerpAPI را اینجا بسازید.

from langchain.agents import load_tools
from smolagents import CodeAgent, InferenceClientModel, Tool

search_tool = Tool.from_langchain(load_tools(["serpapi"])[0])

agent = CodeAgent(tools=[search_tool], model=model)

agent.run("Search for luxury entertainment ideas for a superhero-themed event, such as live performances and interactive experiences.")

وارد کردن یک مجموعه ابزار از هر سرور MCP

smolagents همچنین اجازه می‌دهد ابزارها را از صدها سرور MCP موجود در glama.ai یا smithery.ai وارد کنید. اگر می‌خواهید بیشتر درباره MCP بدانید، می‌توانید دوره رایگان MCP ما را ببینید.

نصب کلاینت mcp

ابتدا باید یکپارچه‌سازی mcp برای smolagents را نصب کنیم.

pip install "smolagents[mcp]"

ابزارهای سرورهای MCP را می‌توان به صورت زیر در یک شیء ToolCollection بارگذاری کرد:

import os
from smolagents import ToolCollection, CodeAgent
from mcp import StdioServerParameters
from smolagents import InferenceClientModel


model = InferenceClientModel("Qwen/Qwen2.5-Coder-32B-Instruct")


server_parameters = StdioServerParameters(
    command="uvx",
    args=["--quiet", "pubmedmcp@0.1.3"],
    env={"UV_PYTHON": "3.12", **os.environ},
)

with ToolCollection.from_mcp(server_parameters, trust_remote_code=True) as tool_collection:
    agent = CodeAgent(tools=[*tool_collection.tools], model=model, add_base_tools=True)
    agent.run("Please find a remedy for hangover.")

با این پیکربندی، آلفرد می‌تواند به‌سرعت گزینه‌های سرگرمی لوکس را کشف کند و تجربه‌ای فراموش‌نشدنی برای نخبگان گاتهام رقم بزند. این ابزار به او کمک می‌کند رویداد ابرقهرمانی بی‌نقصی را در عمارت وین سازماندهی کند! 🎉
