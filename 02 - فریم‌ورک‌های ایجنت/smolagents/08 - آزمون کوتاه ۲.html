خانه/۰۲.۱ — فریم‌ورک smolagents/آزمون کوتاه ۲

آزمون کوتاه ۲ (بدون نمره): ابزارها و انواع ایجنت‌ها

وقت آن است که درک خود از بخش‌های ایجنت‌های کد، ایجنت‌های فراخوان ابزار و ابزارها را بسنجید. این آزمون اختیاری است و نمره ندارد.

سوال ۱: تفاوت کلیدی بین ساخت ابزار با دکوراتور @tool و ساخت زیرکلاس از Tool در smolagents چیست؟

کدام گزاره بهترین توصیف از تمایز بین این دو رویکرد برای تعریف ابزار است؟

استفاده از دکوراتور @tool برای ابزارهای مبتنی بر بازیابی اجباری است، در حالی که زیرکلاس‌های Tool فقط برای تسک‌های تولید متن‌اند.
نادرست: هر دو رویکرد برای هر نوع ابزار، از جمله ابزارهای مبتنی بر بازیابی یا تولید متن، قابل استفاده‌اند.
دکوراتور @tool برای ابزارهای ساده مبتنی بر تابع توصیه می‌شود، در حالی که زیرکلاس‌های Tool برای قابلیت‌های پیچیده یا فراداده سفارشی انعطاف بیشتری دارند.
درست است! درست است. رویکرد دکوراتور ساده‌تر است، اما زیرکلاس‌سازی رفتار سفارشی‌تری را ممکن می‌کند.
@tool فقط در سیستم‌های چند ایجنتی قابل استفاده است، در حالی که ساخت زیرکلاس Tool برای سناریوهای تک‌ایجنتی است.
نادرست: همه ایجنت‌ها (تکی یا چندگانه) می‌توانند از هر دو رویکرد برای تعریف ابزار استفاده کنند؛ چنین محدودیتی وجود ندارد.
تزیین یک تابع با @tool نیاز به docstring را برطرف می‌کند، در حالی که زیرکلاس‌ها نباید docstring داشته باشند.
نادرست: هر دو روش از docstring واضح بهره می‌برند. دکوراتور جایگزین آن نمی‌شود و زیرکلاس هم می‌تواند docstring داشته باشد.

سوال ۲: یک CodeAgent با رویکرد ReAct (استدلال + اکشن) تسک‌های چندمرحله‌ای را چگونه مدیریت می‌کند؟

کدام گزاره درست توصیف می‌کند CodeAgent چگونه مجموعه‌ای از مراحل را برای حل یک تسک اجرا می‌کند؟

هر مرحله را به یک ایجنت متفاوت در سیستم چند ایجنتی می‌سپارد و سپس نتایج را ترکیب می‌کند.
نادرست: هرچند سیستم‌های چند ایجنتی می‌توانند تسک‌ها را توزیع کنند، خود CodeAgent با ReAct می‌تواند چندین مرحله را به‌تنهایی مدیریت کند.
هر اکشن را برای پارس آسان در JSON ذخیره می‌کند و سپس همه را یکجا اجرا می‌کند.
نادرست: این رفتار با رویکرد مبتنی بر JSON در ToolCallingAgent مطابقت دارد، نه CodeAgent.
چرخه‌ای از نوشتن افکار درونی، تولید کد پایتون، اجرای کد و ثبت نتایج را طی می‌کند تا به پاسخ نهایی برسد.
درست است! درست است. این همان الگوی ReAct است که CodeAgent به کار می‌برد، شامل استدلال تکرارشونده و اجرای کد.
پیش از رفتن به مرحله بعد، برای اعتبارسنجی خروجی کد به یک ماژول بینایی تکیه می‌کند.
نادرست: قابلیت‌های بینایی در smolagents پشتیبانی می‌شوند، اما برای CodeAgent یا رویکرد ReAct یک الزام پیش‌فرض نیستند.

سوال ۳: کدام مورد یکی از مزیت‌های اصلی اشتراک‌گذاری یک ابزار در Hugging Face Hub است؟

بهترین دلیل برای آپلود و اشتراک‌گذاری ابزار سفارشی توسط یک توسعه‌دهنده را انتخاب کنید.

ابزار را به‌طور خودکار برای تولید افزوده با بازیابی با یک MultiStepAgent یکپارچه می‌کند.
نادرست: اشتراک‌گذاری ابزار به‌طور خودکار منطق بازیابی یا چندمرحله‌ای را راه‌اندازی نمی‌کند؛ فقط ابزار را در دسترس قرار می‌دهد.
به دیگران اجازه می‌دهد ابزار شما را کشف، استفاده مجدد و در smolagents خود بدون راه‌اندازی اضافه یکپارچه کنند.
درست است! بله. اشتراک‌گذاری در Hub ابزارها را برای همه (از جمله خودتان) قابل دانلود و استفاده مجدد سریع می‌کند.
تضمین می‌کند فقط CodeAgents می‌توانند ابزار را فراخوانی کنند و ToolCallingAgents نمی‌توانند.
نادرست: هم CodeAgents و هم ToolCallingAgents می‌توانند ابزارهای به اشتراک گذاشته‌شده را فراخوانی کنند. محدودیتی بر اساس نوع ایجنت وجود ندارد.
ابزار شما را به تابعی کاملاً مجهز به قابلیت بینایی برای پردازش تصویر تبدیل می‌کند.
نادرست: اشتراک‌گذاری ابزار عملکرد آن را تغییر نمی‌دهد و به‌طور خودکار قابلیت بینایی اضافه نمی‌کند.

سوال ۴: ToolCallingAgent در نحوه اجرای اکشن‌ها با CodeAgent تفاوت دارد. کدام گزاره درست است؟

گزینه‌ای را انتخاب کنید که نحوه کار ToolCallingAgent را به‌درستی توصیف می‌کند.

ToolCallingAgent فقط با سیستم چند ایجنتی سازگار است، در حالی که CodeAgent می‌تواند مستقل اجرا شود.
نادرست: هر یک از این ایجنت‌ها می‌توانند به‌تنهایی یا بخشی از یک سیستم چند ایجنتی استفاده شوند.
ToolCallingAgent کل استدلال را به یک ایجنت بازیابی جداگانه می‌سپارد و سپس پاسخ نهایی را برمی‌گرداند.
نادرست: ToolCallingAgent همچنان برای استدلال از یک LLM اصلی استفاده می‌کند؛ فقط به ایجنت‌های بازیابی تکیه نمی‌کند.
ToolCallingAgent دستورهای JSON خروجی می‌دهد که فراخوانی‌های ابزار و آرگومان‌ها را مشخص می‌کنند و پارس و اجرا می‌شوند.
درست است! درست است. ToolCallingAgent برای تعریف فراخوانی‌های ابزار از رویکرد JSON استفاده می‌کند.
ToolCallingAgent فقط برای تسک‌های تک‌مرحله‌ای است و پس از فراخوانی یک ابزار به‌طور خودکار متوقف می‌شود.
نادرست: ToolCallingAgent در صورت نیاز می‌تواند مانند CodeAgent چند مرحله را انجام دهد.

سوال ۵: جعبه‌ابزار پیش‌فرض smolagents شامل چه مواردی است و چرا ممکن است از آن استفاده کنید؟

کدام گزاره بهترین توصیف از هدف و محتوای جعبه‌ابزار پیش‌فرض در smolagents است؟

مجموعه‌ای از ابزارهای پرکاربرد مانند جستجوی DuckDuckGo، PythonInterpreterTool و یک ابزار پاسخ نهایی برای نمونه‌سازی سریع فراهم می‌کند.
درست است! درست است. جعبه‌ابزار پیش‌فرض این ابزارهای آماده را برای یکپارچه‌سازی آسان هنگام ساخت ایجنت‌ها دارد.
به‌طور پیش‌فرض فقط از تسک‌های مبتنی بر بینایی مانند طبقه‌بندی تصویر یا OCR پشتیبانی می‌کند.
نادرست: هرچند smolagents می‌تواند قابلیت‌های مبتنی بر بینایی را یکپارچه کند، جعبه‌ابزار پیش‌فرض صرفاً بینایی‌محور نیست.
فقط برای سیستم‌های چند ایجنتی در نظر گرفته شده و با یک CodeAgent تکی ناسازگار است.
نادرست: جعبه‌ابزار پیش‌فرض را هر نوع ایجنتی، چه تکی و چه چندگانه، می‌تواند استفاده کند.
قابلیت‌های پیشرفته مبتنی بر بازیابی را برای پرسش و پاسخ در مقیاس بزرگ از یک vector store اضافه می‌کند.
نادرست: هرچند می‌توانید ابزارهای بازیابی بسازید، جعبه‌ابزار پیش‌فرض به‌طور خودکار قابلیت‌های پیشرفته RAG ارائه نمی‌دهد.
