ساخت سیستم‌های Agentic RAG

نکته: می‌توانید کد را در این نوت‌بوک که با Google Colab قابل اجراست دنبال کنید.

سیستم‌های تولید افزوده با بازیابی (RAG) توانایی‌های بازیابی داده و مدل‌های تولیدی را ترکیب می‌کنند تا پاسخ‌هایی آگاه از زمینه ارائه دهند. برای مثال، پرسش کاربر به یک موتور جستجو داده می‌شود و نتایج بازیابی‌شده همراه با پرسش به مدل ارسال می‌شود. سپس مدل بر اساس پرسش و اطلاعات بازیابی‌شده پاسخ تولید می‌کند.

Agentic RAG (تولید افزوده با بازیابی ایجنتی) سیستم‌های RAG سنتی را با ترکیب ایجنت‌های خودمختار با بازیابی پویای دانش گسترش می‌دهد.

در حالی که سیستم‌های RAG سنتی از یک LLM برای پاسخ دادن به پرسش‌ها بر اساس داده‌های بازیابی‌شده استفاده می‌کنند، Agentic RAG کنترل هوشمند هر دو فرایند بازیابی و تولید را ممکن می‌کند و کارایی و دقت را بهبود می‌دهد.

سیستم‌های RAG سنتی با محدودیت‌های کلیدی روبه‌رو هستند، از جمله تکیه بر یک مرحله بازیابی و تمرکز بر شباهت معنایی مستقیم با پرسش کاربر، که ممکن است اطلاعات مرتبط را از قلم بیندازد.

Agentic RAG این مشکلات را با اجازه دادن به ایجنت برای تدوین خودمختار پرسش‌های جستجو، نقد نتایج بازیابی‌شده و انجام چند مرحله بازیابی حل می‌کند تا خروجی متناسب‌تر و جامع‌تری حاصل شود.

بازیابی پایه با DuckDuckGo

بیایید یک ایجنت ساده بسازیم که بتواند با DuckDuckGo در وب جستجو کند. این ایجنت اطلاعات را بازیابی می‌کند و برای پاسخ به پرسش‌ها آن‌ها را ترکیب می‌کند. با Agentic RAG، ایجنت آلفرد می‌تواند:

  • آخرین روندهای مهمانی ابرقهرمانی را جستجو کند
  • نتایج را طوری پالایش کند که شامل عناصر لوکس باشد
  • اطلاعات را در یک برنامه کامل ترکیب کند

ایجنت آلفرد این کار را به این صورت انجام می‌دهد:

from smolagents import CodeAgent, DuckDuckGoSearchTool, InferenceClientModel

# Initialize the search tool
search_tool = DuckDuckGoSearchTool()

# Initialize the model
model = InferenceClientModel()

agent = CodeAgent(
    model=model,
    tools=[search_tool],
)

# Example usage
response = agent.run(
    "Search for luxury superhero-themed party ideas, including decorations, entertainment, and catering."
)
print(response)

ایجنت این فرایند را دنبال می‌کند:

  1. تحلیل درخواست: ایجنت آلفرد عناصر کلیدی پرسش را شناسایی می‌کند ــ برنامه‌ریزی مهمانی لوکس با تم ابرقهرمانی، با تمرکز بر دکور، سرگرمی و کترینگ.
  2. انجام بازیابی: ایجنت از DuckDuckGo برای جستجوی مرتبط‌ترین و به‌روزترین اطلاعات استفاده می‌کند و اطمینان می‌یابد که با ترجیحات پالایش‌شده آلفرد برای یک رویداد لوکس هم‌خوان است.
  3. ترکیب اطلاعات: پس از جمع‌آوری نتایج، ایجنت آن‌ها را به یک برنامه منسجم و عملی برای آلفرد تبدیل می‌کند که همه جنبه‌های مهمانی را پوشش می‌دهد.
  4. ذخیره برای مراجعه بعدی: ایجنت اطلاعات بازیابی‌شده را برای دسترسی آسان هنگام برنامه‌ریزی رویدادهای آینده ذخیره می‌کند و کارایی را در تسک‌های بعدی بهینه می‌کند.

ابزار پایگاه دانش سفارشی

برای تسک‌های تخصصی، یک پایگاه دانش سفارشی می‌تواند بسیار ارزشمند باشد. بیایید ابزاری بسازیم که از یک پایگاه داده برداری (vector database) از مستندات فنی یا دانش تخصصی پرس‌وجو کند. ایجنت با استفاده از جستجوی معنایی (semantic search) می‌تواند مرتبط‌ترین اطلاعات را برای نیازهای آلفرد پیدا کند.

یک پایگاه داده برداری، نمایش‌های عددی (embedding) متن یا داده‌های دیگر را که توسط مدل‌های یادگیری ماشین ساخته شده‌اند ذخیره می‌کند. این پایگاه با شناسایی معانی مشابه در فضای با ابعاد بالا، جستجوی معنایی را ممکن می‌سازد.

این رویکرد دانش از پیش تعریف‌شده را با جستجوی معنایی ترکیب می‌کند تا برای برنامه‌ریزی رویداد، راهکارهای آگاه از زمینه ارائه دهد. با دسترسی به دانش تخصصی، آلفرد می‌تواند همه جزئیات مهمانی را بی‌نقص کند.

در این مثال ابزاری می‌سازیم که ایده‌های برنامه‌ریزی مهمانی را از یک پایگاه دانش سفارشی بازیابی می‌کند. از یک بازیاب BM25 برای جستجو در پایگاه دانش و بازگرداندن نتایج برتر استفاده می‌کنیم، و از RecursiveCharacterTextSplitter برای تقسیم اسناد به تکه‌های کوچک‌تر جهت جستجوی کارآمدتر.

from langchain_community.docstore.document import Document
from langchain_text_splitters import RecursiveCharacterTextSplitter
from smolagents import Tool
from langchain_community.retrievers import BM25Retriever
from smolagents import CodeAgent, InferenceClientModel

class PartyPlanningRetrieverTool(Tool):
    name = "party_planning_retriever"
    description = "Uses semantic search to retrieve relevant party planning ideas for Alfred’s superhero-themed party at Wayne Manor."
    inputs = {
        "query": {
            "type": "string",
            "description": "The query to perform. This should be a query related to party planning or superhero themes.",
        }
    }
    output_type = "string"

    def __init__(self, docs, **kwargs):
        super().__init__(**kwargs)
        self.retriever = BM25Retriever.from_documents(
            docs, k=5  # Retrieve the top 5 documents
        )

    def forward(self, query: str) -> str:
        assert isinstance(query, str), "Your search query must be a string"

        docs = self.retriever.invoke(
            query,
        )
        return "\nRetrieved ideas:\n" + "".join(
            [
                f"\n\n===== Idea {str(i)} =====\n" + doc.page_content
                for i, doc in enumerate(docs)
            ]
        )

# Simulate a knowledge base about party planning
party_ideas = [
    {"text": "A superhero-themed masquerade ball with luxury decor, including gold accents and velvet curtains.", "source": "Party Ideas 1"},
    {"text": "Hire a professional DJ who can play themed music for superheroes like Batman and Wonder Woman.", "source": "Entertainment Ideas"},
    {"text": "For catering, serve dishes named after superheroes, like 'The Hulk's Green Smoothie' and 'Iron Man's Power Steak.'", "source": "Catering Ideas"},
    {"text": "Decorate with iconic superhero logos and projections of Gotham and other superhero cities around the venue.", "source": "Decoration Ideas"},
    {"text": "Interactive experiences with VR where guests can engage in superhero simulations or compete in themed games.", "source": "Entertainment Ideas"}
]

source_docs = [
    Document(page_content=doc["text"], metadata={"source": doc["source"]})
    for doc in party_ideas
]

# Split the documents into smaller chunks for more efficient search
text_splitter = RecursiveCharacterTextSplitter(
    chunk_size=500,
    chunk_overlap=50,
    add_start_index=True,
    strip_whitespace=True,
    separators=["\n\n", "\n", ".", " ", ""],
)
docs_processed = text_splitter.split_documents(source_docs)

# Create the retriever tool
party_planning_retriever = PartyPlanningRetrieverTool(docs_processed)

# Initialize the agent
agent = CodeAgent(tools=[party_planning_retriever], model=InferenceClientModel())

# Example usage
response = agent.run(
    "Find ideas for a luxury superhero-themed party, including entertainment, catering, and decoration options."
)

print(response)

این ایجنت پیشرفته می‌تواند:

  1. ابتدا مستندات را برای یافتن اطلاعات مرتبط بررسی کند
  2. بینش‌های پایگاه دانش را ترکیب کند
  3. زمینه گفتگو را در حافظه نگه دارد

قابلیت‌های بازیابی پیشرفته

هنگام ساخت سیستم‌های Agentic RAG، ایجنت می‌تواند راهبردهای پیچیده‌ای به کار ببرد، از جمله:

  1. بازنویسی پرسش (Query Reformulation): به جای استفاده از پرسش خام کاربر، ایجنت می‌تواند عبارت‌های جستجوی بهینه‌ای بسازد که بهتر با اسناد هدف تطبیق داشته باشند.
  2. تجزیه پرسش (Query Decomposition): به جای استفاده مستقیم از پرسش کاربر، اگر پرسش شامل چند بخش اطلاعاتی برای جستجو باشد، می‌توان آن را به چند پرسش تجزیه کرد.
  3. گسترش پرسش (Query Expansion): تا حدی شبیه بازنویسی پرسش است اما چندین بار انجام می‌شود تا پرسش در چند عبارت‌بندی مختلف مطرح شود و همه آن‌ها جستجو شوند.
  4. رتبه‌بندی مجدد (Reranking): استفاده از Cross-Encoderها برای اختصاص امتیازهای مرتبط‌بودن جامع‌تر و معنایی‌تر بین اسناد بازیابی‌شده و پرسش جستجو.
  5. بازیابی چندمرحله‌ای (Multi-Step Retrieval): ایجنت می‌تواند چند جستجو انجام دهد و از نتایج اولیه برای شکل دادن به پرسش‌های بعدی استفاده کند.
  6. ادغام منابع (Source Integration): اطلاعات را می‌توان از چند منبع مانند جستجوی وب و مستندات محلی ترکیب کرد.
  7. اعتبارسنجی نتایج (Result Validation): محتوای بازیابی‌شده می‌تواند پیش از گنجاندن در پاسخ‌ها از نظر ارتباط و دقت تحلیل شود.

سیستم‌های Agentic RAG مؤثر نیازمند توجه دقیق به چند جنبه کلیدی هستند. ایجنت باید بر اساس نوع پرسش و زمینه، بین ابزارهای موجود انتخاب کند. سیستم‌های حافظه به حفظ تاریخچه گفتگو و جلوگیری از بازیابی‌های تکراری کمک می‌کنند. داشتن راهبردهای جایگزین (fallback) تضمین می‌کند سیستم حتی وقتی روش‌های اصلی بازیابی شکست می‌خورند همچنان ارزش ایجاد کند. علاوه بر این، پیاده‌سازی مراحل اعتبارسنجی به دقت و مرتبط بودن اطلاعات بازیابی‌شده کمک می‌کند.
