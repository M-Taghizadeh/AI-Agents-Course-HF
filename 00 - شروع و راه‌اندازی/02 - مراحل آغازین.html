خانه/۰۰ — شروع و راه‌اندازی/مراحل آغازین

مراحل آغازین: قدم‌های اول ⛵

اکنون که با ساختار دوره آشنا شدید، مراحل زیر را گام‌به‌گام انجام دهید:

گام ۱: ساخت حساب Hugging Face

اگر هنوز ثبت‌نام نکرده‌اید، حساب کاربری رایگان خود را از طریق این لینک بسازید.

گام ۲: پیوستن به سرور Discord

وارد سرور رسمی دیسکورد شوید: عضویت در سرور.

پس از ورود، در کانال #introduce-yourself خود را معرفی کنید و برای پرسش‌های مرتبط با دوره از کانال courses استفاده کنید.

گام ۳: دنبال کردن سازمان دوره روی هاب

برای دریافت جدیدترین آپدیت‌ها و نوتیفیکیشن‌ها، صفحه سازمانی دوره را دنبال کنید:

به آدرس huggingface.co/agents-course بروید و روی Follow کلیک کنید.

گام ۴: اجرای مدل‌ها به‌صورت محلی با Ollama

اگر سقف اعتبار API یا محدودیت نرخ درخواست (Rate Limit) برای اجرای مدل‌ها دارید، می‌توانید مدل‌ها را با استفاده از Ollama به‌صورت محلی روی سیستم خود اجرا کنید:

۱. نصب Ollama

دستورالعمل‌های نسخه سازگار با سیستم‌عامل خود را از سایت رسمی Ollama دانلود و نصب کنید.

۲. دانلود مدل روی سیستم (Pull)

ollama pull qwen2:7b

۳. اجرای سرویس Ollama در پس‌زمینه

ollama serve
نکته رفع خطا

اگر با خطای address already in use روی پورت ۱۱۴۳۴ روبه‌رو شدید، سرویس Ollama به‌طور خودکار در پس‌زمینه در حال اجرا است و نیازی به اجرای مجدد این دستور ندارید.

۴. استفاده از LiteLLMModel به جای InferenceClientModel

برای اتصال به مدل محلی در پکیج smolagents، ابتدا ابزار litellm را نصب کنید:

pip install 'smolagents[litellm]'

سپس در کدهای پایتون مدل را به شکل زیر مقداردهی کنید:

from smolagents import LiteLLMModel

model = LiteLLMModel(
    model_id="ollama_chat/qwen2:7b",
    api_base="http://127.0.0.1:11434",
    num_ctx=8192,
)
چرا این روش بدون تغییر کد کار می‌کند؟

سرویس Ollama یک رابط سازگار با استاندارد OpenAI روی آدرس محلی ارائه می‌دهد و کلاس LiteLLMModel با تمامی این رابط‌ها هماهنگ است؛ بنابراین بدون تغییر منطق ایجنت، مدل لوکال جایگزین کلاینت ابری می‌شود.
