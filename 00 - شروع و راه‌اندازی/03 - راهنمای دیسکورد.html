خانه/۰۰ — شروع و راه‌اندازی/راهنمای Discord

(اختیاری) راهنمای استفاده از Discord

این راهنما برای شروع کار با دیسکورد (یک پلتفرم چت و گفتگو که در کامیونیتی‌های یادگیری ماشین و برنامه‌نویسی بسیار پرطرفدار است) آماده شده است.

سرور دیسکورد Hugging Face با بیش از ۱۰۰,۰۰۰ عضو، محیطی مناسب برای تعامل و یادگیری است. برای پیوستن می‌توانید از لینک دعوت سرور استفاده کنید.

کانال‌های اختصاصی دوره ایجنت‌ها

پس از پیوستن به سرور، در کانال #introduce-yourself خود را معرفی کنید. کانال‌های زیر مخصوص این دوره ایجاد شده‌اند:

  • agents-course-announcements: برای دریافت آخرین اطلاعیه‌ها و تغییرات دوره.
  • 🎓-agents-course-general: برای گفتگوهای عمومی، تبادل نظر و چت دانشجویان.
  • agents-course-questions: برای طرح پرسش‌ها، رفع اشکال و کمک به هم‌دوره‌ای‌ها.
  • agents-course-showcase: برای نمایش ایجنت‌هایی که ساخته‌اید و دریافت فیدبک.
  • smolagents: برای بحث، گفتگو و پشتیبانی درباره کتابخانه smolagents.

نکات مهم برای استفاده مؤثر از Discord

  • کانال‌های صوتی (Voice Channels): هرچند چت متنی کاربرد بیشتری دارد، اما اتاق‌های صوتی نیز برای مباحث گروهی در دسترس هستند.
  • فرمت Markdown: دیسکورد از نشانه‌گذاری Markdown پشتیبانی می‌کند؛ برای اشتراک کدهای خود حتماً از بک‌تیک سه‌تایی (```python ... ```) استفاده کنید تا خوانایی کد حفظ شود.
  • استفاده از Thread: برای مباحث طولانی یا سوالات مشخص، یک Thread مجزا باز کنید تا جریان چت اصلی در کانال خلوت بماند.
