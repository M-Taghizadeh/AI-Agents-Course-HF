خانه/۰۱ — مبانی ایجنت‌ها/اقدام‌ها و رویکرد Stop and Parse

اقدام‌ها: توانمندسازی ایجنت برای تعامل با محیط (Actions)

نکته

در این بخش، گام‌های مشخصی را که یک ایجنت هوش مصنوعی برای تعامل با محیطش برمی‌دارد بررسی می‌کنیم.

پوشش می‌دهیم که اقدام‌ها چگونه نمایش داده می‌شوند (با JSON یا کد)، اهمیت رویکرد توقف و پارس (Stop and Parse) چیست و انواع مختلف ایجنت‌ها را معرفی می‌کنیم.

اقدام‌ها (Actions) گام‌های مشخصی هستند که یک ایجنت هوش مصنوعی برای تعامل با محیطش برمی‌دارد.

چه گشتن در وب برای یافتن اطلاعات باشد و چه کنترل یک دستگاه فیزیکی، هر اقدام یک عملیات سنجیده است که ایجنت اجرا می‌کند.

برای مثال، ایجنتی که در خدمات مشتریان کمک می‌کند ممکن است داده‌های مشتری را بازیابی کند، مقاله‌های پشتیبانی پیشنهاد دهد یا مسائل را به یک نماینده انسانی ارجاع دهد.

انواع اقدام‌های ایجنت

انواع مختلفی از ایجنت‌ها وجود دارند که اقدام‌ها را به شیوه‌های متفاوتی انجام می‌دهند:

نوع ایجنتتوضیح
ایجنت JSON (JSON Agent)اقدامی که باید انجام شود در قالب JSON مشخص می‌شود.
ایجنت کد (Code Agent)ایجنت یک بلوک کد می‌نویسد که به‌طور خارجی تفسیر (اجرا) می‌شود.
ایجنت فراخوانی تابع (Function-calling Agent)زیرمجموعه‌ای از ایجنت JSON است که ریزتنظیم شده تا برای هر اقدام یک پیام جدید تولید کند.

خود اقدام‌ها هم می‌توانند اهداف متعددی داشته باشند:

نوع اقدامتوضیح
جمع‌آوری اطلاعات (Information Gathering)انجام جستجوهای وب، پرس‌وجو از پایگاه‌های داده یا بازیابی اسناد.
استفاده از ابزار (Tool Usage)فراخوانی APIها، اجرای محاسبات و اجرای کد.
تعامل با محیط (Environment Interaction)دستکاری رابط‌های دیجیتال یا کنترل دستگاه‌های فیزیکی.
ارتباط (Communication)تعامل با کاربران از طریق چت یا همکاری با ایجنت‌های دیگر.

LLM فقط با متن سروکار دارد و از آن برای توصیف اقدامی که می‌خواهد انجام دهد و پارامترهایی که باید به ابزار بدهد استفاده می‌کند. برای اینکه ایجنت درست کار کند، LLM باید پس از تولید همه توکن‌هایی که یک اقدام کامل را تعریف می‌کنند، از تولید توکن‌های جدید باز ایستد (STOP). این کار کنترل را از LLM به ایجنت برمی‌گرداند و تضمین می‌کند نتیجه قابل پارس شدن است، چه قالب موردنظر JSON باشد، چه کد و چه فراخوانی تابع.

رویکرد توقف و پارس (The Stop and Parse Approach)

یکی از روش‌های کلیدی برای پیاده‌سازی اقدام‌ها رویکرد توقف و پارس است. این روش تضمین می‌کند خروجی ایجنت ساختارمند و قابل‌پیش‌بینی باشد:

  1. تولید در یک قالب ساختارمند (Generation in a Structured Format):

    ایجنت اقدام موردنظرش را در یک قالب روشن و از پیش تعیین‌شده (JSON یا کد) خروجی می‌دهد.

  2. توقف تولید بیشتر (Halting Further Generation):

    به محض اینکه متن تعریف‌کننده اقدام تولید شد، LLM از تولید توکن‌های اضافی متوقف می‌شود. این کار از خروجی اضافه یا نادرست جلوگیری می‌کند.

  3. پارس کردن خروجی (Parsing the Output):

    یک پارسر خارجی اقدام فرمت‌شده را می‌خواند، تعیین می‌کند کدام ابزار را باید فراخوانی کند و پارامترهای موردنیاز را استخراج می‌کند.

برای مثال، ایجنتی که باید آب‌وهوا را بررسی کند ممکن است این خروجی را بدهد:

Thought: I need to check the current weather for New York.
Action :
{
  "action": "get_weather",
  "action_input": {"location": "New York"}
}

سپس فریم‌ورک می‌تواند به‌آسانی نام تابعی را که باید فراخوانی شود و آرگومان‌هایی را که باید اعمال شوند پارس کند.

این قالب روشن و قابل‌خواندن برای ماشین، خطاها را به حداقل می‌رساند و به ابزارهای خارجی امکان می‌دهد فرمان ایجنت را دقیق پردازش کنند.

توجه: ایجنت‌های فراخوانی تابع به شیوه مشابهی کار می‌کنند، با این تفاوت که هر اقدام را طوری ساختار می‌دهند که تابعی مشخص با آرگومان‌های درست فراخوانی شود. در یک فصل بعدی عمیق‌تر به این نوع ایجنت‌ها می‌پردازیم.

ایجنت‌های کد (Code Agents)

رویکرد جایگزین استفاده از ایجنت‌های کد است. ایده این است: به جای خروجی دادن یک آبجکت ساده JSON، ایجنت کد یک بلوک کد اجرایی تولید می‌کند، معمولاً در یک زبان سطح بالا مثل پایتون.

این رویکرد مزایای متعددی دارد:

  • گویایی (Expressiveness): کد می‌تواند منطق پیچیده، از جمله حلقه‌ها، شرط‌ها و توابع تودرتو را به‌طور طبیعی نمایش دهد و انعطاف بیشتری از JSON فراهم کند.
  • مدولار بودن و قابلیت استفاده مجدد (Modularity and Reusability): کد تولیدشده می‌تواند شامل توابع و ماژول‌هایی باشد که در اقدام‌ها یا تسک‌های مختلف قابل استفاده مجدد هستند.
  • دیباگ‌پذیری بهتر (Enhanced Debuggability): با یک سینتکس برنامه‌نویسی مشخص، خطاهای کد اغلب راحت‌تر شناسایی و اصلاح می‌شوند.
  • یکپارچگی مستقیم (Direct Integration): ایجنت‌های کد می‌توانند مستقیماً با کتابخانه‌ها و APIهای خارجی یکپارچه شوند و عملیات پیچیده‌تری مثل پردازش داده یا تصمیم‌گیری بلادرنگ را ممکن کنند.

باید به یاد داشته باشید که اجرای کدی که LLM تولید کرده ممکن است ریسک‌های امنیتی داشته باشد، از تزریق پرامپت (Prompt Injection) گرفته تا اجرای کد مخرب. به همین دلیل توصیه می‌شود از فریم‌ورک‌های ایجنت هوش مصنوعی مثل smolagents استفاده شود که حفاظ‌های پیش‌فرض را یکپارچه کرده‌اند. اگر می‌خواهید درباره ریسک‌ها و روش‌های کاهش آن‌ها بیشتر بدانید، لطفاً به این بخش اختصاصی نگاهی بیندازید.

برای مثال، یک ایجنت کد که مأمور دریافت آب‌وهواست ممکن است قطعه کد پایتون زیر را تولید کند:

# Code Agent Example: Retrieve Weather Information
def get_weather(city):
    import requests
    api_url = f"https://api.weather.com/v1/location/{city}?apiKey=YOUR_API_KEY"
    response = requests.get(api_url)
    if response.status_code == 200:
        data = response.json()
        return data.get("weather", "No weather information available")
    else:
        return "Error: Unable to fetch weather data."

# Execute the function and prepare the final answer
result = get_weather("New York")
final_answer = f"The current weather in New York is: {result}"
print(final_answer)

در این مثال، ایجنت کد:

  • داده‌های آب‌وهوا را از طریق یک فراخوانی API بازیابی می‌کند،
  • پاسخ را پردازش می‌کند،
  • و از تابع print() برای خروجی دادن پاسخ نهایی استفاده می‌کند.

این روش هم‌زمان از رویکرد توقف و پارس نیز پیروی می‌کند، چون بلوک کد را به‌روشنی مشخص می‌کند و پایان اجرا را اعلام می‌کند (در اینجا با چاپ final_answer).

یاد گرفتیم که اقدام‌ها پلی میان استدلال درونی ایجنت و تعامل‌های دنیای واقعی آن هستند و این کار را با اجرای وظایف روشن و ساختارمند انجام می‌دهند، چه از طریق JSON، چه کد و چه فراخوانی تابع.

این اجرای سنجیده تضمین می‌کند هر اقدام دقیق است و از طریق رویکرد توقف و پارس برای پردازش خارجی آماده است. در بخش بعد، مشاهدات (Observations) را بررسی می‌کنیم تا ببینیم ایجنت‌ها چگونه بازخورد محیط را دریافت و یکپارچه می‌کنند.

بعد از آن، بالاخره آماده می‌شویم اولین ایجنت خودمان را بسازیم!
